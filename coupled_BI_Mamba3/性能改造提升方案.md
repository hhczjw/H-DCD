## 改造全景概览

```
改造前架构:
  BERT-base(768) + Linear(74→128) + Linear(35→128)
       ↓                ↓                ↓
  ISM ×3          ISM ×3          ISM ×3
       ↓                ↓                ↓
  CoupledMamba3Fork (v_self_ratio=0, 无门控)
       ↓
  Mean Pool → Concat → Classifier
  (无上下文, 无子任务监督, dropout=0.1, 学习率不分层)

改造后架构:
  RoBERTa-base/large + Data2Vec-Audio + CLIP/VideoMAE/OpenFace
       ↓                ↓                ↓
  ISM ×1          ISM ×1          ISM ×1     ← ISM 深度降低
       ↓                ↓                ↓
  Pool → [Context, Main] 特征级拼接 (序列长度=2)
       ↓
  GatedCoupledMamba3Fork (门控融合 + v_self_ratio=0.3)
       ↓
  Mean Pool → Concat → Classifier + sub_T/A/V 辅助头
  (dropout=0.3, 8组分层学习率, L1Loss, 多任务损失)
```

### CoupledMamba3Fork 在改造后架构中的双重角色

改造后，`CoupledMamba3Fork` **同时承担两个职责**：

**角色一：跨模态融合**（原有角色，保持不变）

```
         Audio ──→ Q_A ← K/V 来自 V+L
        Visual ──→ Q_V ← K/V 来自 A+L
       Lexical ──→ Q_L ← K/V 来自 A+V
```

每个目标模态的 Q 来自自身，K/V 由另外两个源模态的加权融合提供。

**角色二：对话上下文时序建模**（新增角色）

```
时间步 t=0 (context):  SSM 状态 h₀ 编码上下文情感信息
        ↓  data-dependent A (选择性记忆)
时间步 t=1 (main):     SSM 状态 h₁ = f(h₀, A, B, x_main)
                       Q 从 h₁ 中读取 → 融合了上下文信息的主话语表征
```

Mamba SSM 的 selective scan 自动学习「上下文如何影响当前话语的情感表达」。

| 职责分离 | ISMEncoder | CoupledMamba3Fork |
|---------|------------|-------------------|
| 处理层次 | 帧级时序（同一话语内） | 对话级时序（跨话语） |
| 序列长度 | 50（帧数） | 2（context→main） |
| 建模内容 | 帧间依赖关系 | 跨模态交互 + 情感转移 |

### 2.3 代码改造

#### 2.3.1 新建 `TextPretrainedEncoder` — 替换原有的 `BertTextEncoder`

**文件**: `coupled_BI_Mamba3/models/classifier.py`

```python
# ============================================================
# 改造: 通用文本预训练编码器 (支持 BERT/RoBERTa/DeBERTa 等)
# 替换原有的 BertTextEncoder 类
# ============================================================

class TextPretrainedEncoder(nn.Module):
    """
    通用文本预训练编码器, 支持 BERT / RoBERTa / DeBERTa 等 HuggingFace 模型.
    
    与原有 BertTextEncoder 的差异:
    1. 支持 RoBERTa (无 token_type_ids, 使用 <s>/</s> 分隔符)
    2. 支持 DeBERTa (相对位置编码)
    3. 自动检测模型类型, 适配不同的输入格式
    4. 支持在线编码 (从原始文本而非离线特征)
    """

    # 预定义模型配置映射
    SUPPORTED_MODELS = {
        "bert-base-uncased":    {"dim": 768, "type": "bert"},
        "bert-large-uncased":   {"dim": 1024, "type": "bert"},
        "roberta-base":         {"dim": 768, "type": "roberta"},
        "roberta-large":        {"dim": 1024, "type": "roberta"},
        "microsoft/deberta-base": {"dim": 768, "type": "deberta"},
    }

    def __init__(
        self,
        pretrained: str = "roberta-base",      # ★ 默认改为 RoBERTa-base
        finetune: bool = True,
        strict: bool = True,
    ):
        super().__init__()
        self.pretrained_name = pretrained
        self.use_hf = False
        
        # 自动检测模型类型
        self.model_type = "bert"  # fallback
        for key, info in self.SUPPORTED_MODELS.items():
            if key in pretrained.lower():
                self.model_type = info["type"]
                self.out_dim = info["dim"]
                break
        
        try:
            from transformers import AutoModel, AutoTokenizer
            self.tokenizer = AutoTokenizer.from_pretrained(pretrained)
            self.transformer = AutoModel.from_pretrained(pretrained)
            self.out_dim = self.transformer.config.hidden_size
            self.use_hf = True
        except Exception as e:
            if strict:
                raise RuntimeError(f"加载 {pretrained} 失败: {e}")
            print(f"[WARN] 回退到 Embedding: {e}")
            self.transformer = nn.Embedding(50265, self.out_dim, padding_idx=1)
            self.tokenizer = None

        if self.use_hf and not finetune:
            for p in self.transformer.parameters():
                p.requires_grad = False

    def forward(
        self, text_input: torch.Tensor
    ) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        Args:
            text_input: 
                - 离线三通道模式 (兼容旧接口): (B, 3, L)
                - 在线模式: (B, L) 仅 input_ids
        Returns:
            hidden:         (B, L, out_dim)
            attention_mask: (B, L) long
        """
        if text_input.dim() == 3 and text_input.size(1) == 3:
            # 兼容旧的三通道格式: [ids, mask, segment]
            input_ids = text_input[:, 0].long()
            attention_mask = text_input[:, 1].long()
            token_type_ids = text_input[:, 2].long()
        elif text_input.dim() == 2:
            input_ids = text_input.long()
            attention_mask = (input_ids != self.tokenizer.pad_token_id).long() \
                if self.tokenizer else (input_ids != 0).long()
            token_type_ids = None
        else:
            input_ids = text_input.squeeze(1).long()
            attention_mask = (input_ids != 0).long()
            token_type_ids = None

        if not self.use_hf:
            return self.transformer(input_ids), attention_mask

        # 根据模型类型适配参数
        kw = {"input_ids": input_ids, "attention_mask": attention_mask}
        if self.model_type == "bert":
            if token_type_ids is not None:
                kw["token_type_ids"] = token_type_ids
        # RoBERTa / DeBERTa 不需要 token_type_ids
        
        out = self.transformer(**kw)
        return out.last_hidden_state, attention_mask
```

### 3.3 离线特征提取脚本

**新建文件**: `coupled_BI_Mamba3/scripts/extract_audio_pretrained.py`

```python
#!/usr/bin/env python3
"""
离线提取预训练音频特征, 替代 COVAREP 手工特征.

用法:
    python scripts/extract_audio_pretrained.py \
        --model_name facebook/data2vec-audio-base-960h \
        --audio_dir /path/to/raw_audio/ \
        --output /path/to/audio_data2vec.pkl \
        --target_frames 50 \
        --batch_size 16

支持的模型:
    - facebook/data2vec-audio-base-960h      (768 维)
    - facebook/data2vec-audio-large-960h     (1024 维)
    - microsoft/wavlm-base-plus              (768 维)
    - facebook/hubert-base-ls960             (768 维)
"""

import argparse
import os
import pickle
import numpy as np
import torch
import torch.nn.functional as F
from tqdm import tqdm
from transformers import AutoProcessor, AutoModel
import soundfile as sf


def load_audio(audio_path: str, target_sr: int = 16000) -> np.ndarray:
    """加载并重采样音频到 16kHz."""
    audio, sr = sf.read(audio_path)
    if audio.ndim > 1:
        audio = audio.mean(axis=1)  # 立体声→单声道
    if sr != target_sr:
        import librosa
        audio = librosa.resample(
            audio, orig_sr=sr, target_sr=target_sr
        )
    return audio.astype(np.float32)


def extract_features(
    model,
    processor,
    audio: np.ndarray,
    target_frames: int = 50,
    device: str = "cuda",
) -> np.ndarray:
    """
    提取预训练音频特征并聚合到 target_frames 帧.

    Args:
        model: HuggingFace 预训练音频模型
        processor: 对应的 processor
        audio: (T,) 原始音频波形
        target_frames: 目标帧数 (对齐文本帧数)
        device: cuda/cpu

    Returns:
        features: (target_frames, hidden_dim)
    """
    # 预处理
    inputs = processor(
        audio, sampling_rate=16000, return_tensors="pt"
    ).to(device)

    with torch.no_grad():
        outputs = model(**inputs, output_hidden_states=True)
        hidden = outputs.last_hidden_state  # (1, T_raw, hidden_dim)

    # 聚合到目标帧数
    hidden = hidden.squeeze(0)  # (T_raw, D)
    if hidden.size(0) != target_frames:
        hidden = F.adaptive_avg_pool1d(
            hidden.T.unsqueeze(0), target_frames
        ).squeeze(0).T  # (target_frames, D)

    return hidden.cpu().numpy()


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--model_name", type=str,
        default="facebook/data2vec-audio-base-960h"
    )
    parser.add_argument("--audio_dir", type=str, required=True)
    parser.add_argument("--output", type=str, required=True)
    parser.add_argument("--target_frames", type=int, default=50)
    parser.add_argument("--batch_size", type=int, default=16)
    parser.add_argument("--device", type=str, default="cuda")
    args = parser.parse_args()

    device = torch.device(
        args.device if torch.cuda.is_available() else "cpu"
    )
    print(f"Loading {args.model_name}...")
    processor = AutoProcessor.from_pretrained(
        args.model_name, trust_remote_code=True
    )
    model = AutoModel.from_pretrained(args.model_name).to(device)
    model.eval()

    # 扫描音频文件
    audio_files = sorted([
        f for f in os.listdir(args.audio_dir)
        if f.endswith(('.wav', '.flac', '.mp3'))
    ])
    print(f"Found {len(audio_files)} audio files")

    all_features = []
    hidden_dim = model.config.hidden_size
    for audio_file in tqdm(audio_files):
        audio_path = os.path.join(args.audio_dir, audio_file)
        try:
            audio = load_audio(audio_path)
            feats = extract_features(

            all_features.append(

            )

    features_array = np.stack(all_features, axis=0)  # (N, T, D)
    print(f"Extracted features shape: {features_array.shape}")

    with open(args.output, "wb") as f:
        pickle.dump({"audio": features_array}, f)
    print(f"Saved to {args.output}")


if __name__ == "__main__":
    main()
```

### 3.5 补充: Data2Vec 有效帧定位机制 ★ CAGMamba 关键技术

> CAGMamba 使用 attention map 自动定位音频有效帧（非 padding 帧），而非简单的 `adaptive_avg_pool1d`。这比手工特征替换为预训练特征更为关键——因为它确保了 **只有真正有效的音频信息进入融合层**。

**CAGMamba 的实现**（来自 `msamba_mmml_model.py::extract_audio_features`）：

```python
def extract_audio_features(self, audio_inputs, audio_mask):
    """提取音频特征 — ★ 使用 attention map 定位有效帧"""
    audio_out = self.data2vec_model(
        audio_inputs, audio_mask, output_attentions=True
    )
    hidden_states = audio_out.last_hidden_state

    # ★ 关键: 通过 attention map 自动定位有效帧边界
    valid_features = []
    for batch in range(hidden_states.shape[0]):
        layer = 0
        while layer < 12:
            try:
                # attention[layer][batch][0][0] 的第一个 token 对其他 token 的注意力
                # 值非零的位置 = 有效帧，值为零的位置 = padding
                padding_idx = sum(
                    audio_out.attentions[layer][batch][0][0] != 0
                )
                break
            except:
                layer += 1

        if layer < 12:
            # 只对有效帧做 mean pooling
            valid_feature = torch.mean(
                hidden_states[batch][:padding_idx], 0
            )
        else:
            valid_feature = torch.mean(hidden_states[batch], 0)
        valid_features.append(valid_feature)

    pooler_output = torch.stack(valid_features, 0)
    return hidden_states, pooler_output
```

**为什么这很重要**：
- Data2Vec 输出的时间帧数可能远超目标帧数（如 96000 采样点 → ~300 帧）
- `adaptive_avg_pool1d` 会把 padding 区域的零向量也纳入均值，稀释有效信息
- Attention-based 定位**精确地**只对包含语音的帧进行池化，保留完整的声学信息

**Coupled-BI-Mamba3 的改造建议**：

当使用 Data2Vec 在线编码时，应实现类似的 `extract_audio_features` 方法，替代 `AudioVideoProjection` 中简单的 `adaptive_avg_pool1d` 对齐。

```
改造前 (AudioVideoProjection):
  手工特征 (B, L, 74) → Linear(74→128) → 输出

改造后 (AudioPretrainedEncoder):
  原始波形 → Data2Vec → Attention-based 有效帧检测
  → Mean Pool (仅有效帧) → Linear(768→128) → 输出
```

### 4.4 视频特征提取脚本 (方案A: CLIP)

**新建文件**: `coupled_BI_Mamba3/scripts/extract_video_clip.py`

```python
#!/usr/bin/env python3
"""
离线提取 CLIP-ViT 视觉特征, 替代 FACET 手工特征.

用法:
    python scripts/extract_video_clip.py \
        --model_name openai/clip-vit-base-patch32 \
        --video_dir /path/to/videos/ \
        --output /path/to/vision_clip.pkl \
        --num_frames 50 \
        --batch_size 32

依赖: pip install open-clip-torch torchvision opencv-python
"""

import argparse
import os
import pickle
import numpy as np
import torch
import torch.nn.functional as F
from tqdm import tqdm
from PIL import Image
import torchvision.transforms as T


def get_clip_transform(image_size: int = 224):
    """CLIP 标准预处理."""
    return T.Compose([
        T.Resize(
            image_size,
            interpolation=T.InterpolationMode.BICUBIC
        ),
        T.CenterCrop(image_size),
        T.ToTensor(),
        T.Normalize(
            (0.48145466, 0.4578275, 0.40821073),
            (0.26862954, 0.26130258, 0.27577711),
        ),
    ])


def extract_video_frames(
    video_path: str, num_frames: int = 50
) -> list:
    """均匀采样视频帧."""
    import cv2
    cap = cv2.VideoCapture(video_path)
    total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    if total_frames <= 0:
        cap.release()
        return []

    indices = np.linspace(
        0, total_frames - 1, num_frames, dtype=int
    )
    frames = []
    for idx in indices:
        cap.set(cv2.CAP_PROP_POS_FRAMES, idx)
        ret, frame = cap.read()
        if ret:
            frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            frames.append(Image.fromarray(frame))
    cap.release()

    # 帧数不足时用最后一帧填充
    while len(frames) < num_frames:
        frames.append(
            frames[-1]
            if frames
            else Image.new('RGB', (224, 224))
        )
    return frames[:num_frames]


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--model_name", type=str,
        default="openai/clip-vit-base-patch32"
    )
    parser.add_argument("--video_dir", type=str, required=True)
    parser.add_argument("--output", type=str, required=True)
    parser.add_argument("--num_frames", type=int, default=50)
    parser.add_argument("--batch_size", type=int, default=32)
    parser.add_argument("--device", type=str, default="cuda")
    args = parser.parse_args()

    device = torch.device(
        args.device if torch.cuda.is_available() else "cpu"
    )

    # 加载 CLIP 模型
    import open_clip
    model, _, preprocess = open_clip.create_model_and_transforms(
        'ViT-B-32', pretrained='laion2b_s34b_b79k'
    )
    model = model.visual.to(device)
    model.eval()

    transform = get_clip_transform(224)

    video_files = sorted([
        f for f in os.listdir(args.video_dir)
        if f.endswith(('.mp4', '.avi', '.mov', '.mkv'))
    ])
    print(f"Found {len(video_files)} videos")

    all_features = []
    for video_file in tqdm(video_files):
        video_path = os.path.join(args.video_dir, video_file)
        try:
            frames = extract_video_frames(
                video_path, args.num_frames
            )
            if not frames:
                all_features.append(
                    np.zeros((args.num_frames, 768),
                             dtype=np.float32)
                )
                continue

            frame_tensors = torch.stack(
                [transform(f) for f in frames]
            ).to(device)
            with torch.no_grad():
                feats_list = []
                for i in range(
                    0, len(frame_tensors), args.batch_size
                ):
                    batch = frame_tensors[i:i+args.batch_size]
                    feats = model(batch)
                    feats_list.append(feats.cpu())
                feats = torch.cat(feats_list, dim=0)
            all_features.append(feats.numpy())
        except Exception as e:
            print(f"Error processing {video_file}: {e}")
            all_features.append(
                np.zeros((args.num_frames, 768),
                         dtype=np.float32)
            )

    features_array = np.stack(all_features, axis=0)  # (N, T, 768)
    print(f"Extracted features shape: {features_array.shape}")

    with open(args.output, "wb") as f:
        pickle.dump({"vision": features_array}, f)
    print(f"Saved to {args.output}")


if __name__ == "__main__":
    main()
```

### 4.5 视频特征提取脚本 (方案C: OpenFace 2.0)

**新建文件**: `coupled_BI_Mamba3/scripts/extract_video_openface.py`

```python
#!/usr/bin/env python3
"""
离线提取 OpenFace 2.0 面部行为特征, 替代 FACET 手工特征.

用法:
    python scripts/extract_video_openface.py \
        --openface_dir /path/to/OpenFace/build/bin \
        --video_dir /path/to/videos/ \
        --output /path/to/vision_openface.pkl \
        --num_frames 50

依赖: OpenFace 2.0 (系统级安装, 见下方说明)

OpenFace 2.0 安装 (Ubuntu):
    git clone https://github.com/TadasBaltrusaitis/OpenFace.git
    cd OpenFace
    ./download_models.sh
    mkdir build && cd build
    cmake -D CMAKE_BUILD_TYPE=RELEASE ..
    make -j$(nproc)
    # 二进制文件位置: OpenFace/build/bin/FeatureExtraction

输出特征维度 (~714 维/帧):
    - Facial Landmarks: 68 点 × 2D (136 维) or 3D (204 维)
    - Head Pose: T_x, T_y, T_z, R_x, R_y, R_z (6 维)
    - Eye Gaze: left/right eye direction vectors (8 维)
    - Action Units (intensity): AU01~AU45 中 17 个 (17 维)
    - HOG features: 446 维 (可选)
    - 总计默认: ~714 维 (不含 3D landmarks 和 HOG)
"""

import argparse
import os
import pickle
import subprocess
import tempfile
import numpy as np
from tqdm import tqdm
import pandas as pd


def extract_openface_features(
    video_path: str,
    openface_bin: str,
    output_dir: str,
) -> str:
    """
    调用 OpenFace FeatureExtraction 提取单视频特征.

    Args:
        video_path: 视频文件路径
        openface_bin: FeatureExtraction 二进制路径
        output_dir: 输出目录

    Returns:
        csv_path: 输出 CSV 文件路径
    """
    video_name = os.path.splitext(os.path.basename(video_path))[0]
    cmd = [
        openface_bin,
        "-f", video_path,
        "-out_dir", output_dir,
        "-2Dfp",          # 2D facial landmarks
        "-3Dfp",          # 3D facial landmarks (更多维)
        "-pdmparams",     # head pose
        "-pose",
        "-aus",           # action units
        "-gaze",          # eye gaze
        "-hogalign",      # HOG features (可选, 446 维)
        "-q",             # quiet mode
    ]
    subprocess.run(cmd, check=True, capture_output=True)
    csv_path = os.path.join(output_dir, f"{video_name}.csv")
    return csv_path


def load_openface_csv(csv_path: str) -> np.ndarray:
    """
    解析 OpenFace CSV 为特征矩阵.

    OpenFace CSV 列说明:
        - frame: 帧序号
        - x_0~x_67, y_0~y_67: 2D landmarks (136 维)
        - pose_Tx, pose_Ty, pose_Tz, pose_Rx, pose_Ry, pose_Rz (6 维)
        - gaze_0_x~gaze_1_z: eye gaze (8 维)
        - AU01_r~AU45_r: action units intensity (17 维)

    返回: (num_frames, feature_dim)
    """
    df = pd.read_csv(csv_path)

    # 选择特征列
    feature_cols = []

    # 2D landmarks: x_0~x_67, y_0~y_67
    lm_cols = [c for c in df.columns
               if c.startswith(('x_', 'y_'))
               and c[2:].isdigit()
               and int(c[2:]) < 68]
    feature_cols.extend(lm_cols)

    # Head pose
    pose_cols = [c for c in df.columns
                 if c.startswith('pose_')]
    feature_cols.extend(pose_cols)

    # Eye gaze
    gaze_cols = [c for c in df.columns
                 if c.startswith('gaze_')]
    feature_cols.extend(gaze_cols)

    # Action units (intensity: AU*_r)
    au_cols = [c for c in df.columns
               if c.startswith('AU') and c.endswith('_r')]
    feature_cols.extend(au_cols)

    # 提取特征
    features = df[feature_cols].values.astype(np.float32)
    # 填充 NaN (人脸检测失败帧)
    features = np.nan_to_num(features, nan=0.0)

    return features


def align_frames(
    features: np.ndarray, num_frames: int
) -> np.ndarray:
    """
    将变长帧序列对齐到 num_frames 帧.

    Args:
        features: (T_raw, D)
        num_frames: 目标帧数

    Returns:
        aligned: (num_frames, D)
    """
    T_raw, D = features.shape
    if T_raw == 0:
        return np.zeros((num_frames, D), dtype=np.float32)

    if T_raw == num_frames:
        return features

    # 均匀采样
    indices = np.linspace(0, T_raw - 1, num_frames, dtype=int)
    return features[indices]


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--openface_dir", type=str, required=True,
        help="OpenFace 安装目录 (如 /path/to/OpenFace/build/bin)"
    )
    parser.add_argument("--video_dir", type=str, required=True)
    parser.add_argument("--output", type=str, required=True)
    parser.add_argument("--num_frames", type=int, default=50)
    args = parser.parse_args()

    openface_bin = os.path.join(
        args.openface_dir, "FeatureExtraction"
    )
    if not os.path.isfile(openface_bin):
        raise FileNotFoundError(
            f"OpenFace FeatureExtraction not found at {openface_bin}\n"
            f"请确认 OpenFace 2.0 已正确安装。"
        )

    video_files = sorted([
        f for f in os.listdir(args.video_dir)
        if f.endswith(('.mp4', '.avi', '.mov', '.mkv'))
    ])
    print(f"Found {len(video_files)} videos")

    all_features = []
    with tempfile.TemporaryDirectory() as tmpdir:
        for video_file in tqdm(video_files):
            video_path = os.path.join(args.video_dir, video_file)
            feat_dim = None
            try:
                csv_path = extract_openface_features(
                    video_path, openface_bin, tmpdir
                )
                feats = load_openface_csv(csv_path)
                feats = align_frames(feats, args.num_frames)
                all_features.append(feats)
            except Exception as e:
                print(f"Error processing {video_file}: {e}")
                # 如果第一个视频成功, 用其维度填充
                if feat_dim is None and all_features:
                    feat_dim = all_features[-1].shape[-1]
                if feat_dim is None:
                    feat_dim = 714  # 默认维度
                all_features.append(
                    np.zeros((args.num_frames, feat_dim),
                             dtype=np.float32)
                )

    features_array = np.stack(all_features, axis=0)  # (N, T, D)
    print(f"Extracted features shape: {features_array.shape}")

    with open(args.output, "wb") as f:
        pickle.dump({"vision": features_array}, f)
    print(f"Saved to {args.output}")


if __name__ == "__main__":
    main()
```

### 4.6 视频特征提取脚本 (方案B: VideoMAE)

```python
#!/usr/bin/env python3
"""
离线提取 VideoMAE 视觉特征.

用法:
    python scripts/extract_video_videomae.py \
        --model_name MCG-NJU/videomae-base \
        --video_dir /path/to/videos/ \

import os

import numpy as np
import torch
import torch.nn.functional as F
from tqdm import tqdm
from transformers import VideoMAEImageProcessor, VideoMAEModel
import cv2


def extract_video_frames(
    video_path: str, num_frames: int = 16
) -> np.ndarray:
    """均匀采样视频帧, 返回 (num_frames, H, W, C) uint8 数组."""
    cap = cv2.VideoCapture(video_path)
    total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    if total_frames <= 0:
        cap.release()
        return np.zeros((num_frames, 224, 224, 3), dtype=np.uint8)

    indices = np.linspace(
        0, total_frames - 1, num_frames, dtype=int
    )
    frames = []
    for idx in indices:
        cap.set(cv2.CAP_PROP_POS_FRAMES, idx)
        ret, frame = cap.read()
        if ret:
            frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            frame = cv2.resize(frame, (224, 224))
            frames.append(frame)
    cap.release()

    while len(frames) < num_frames:
        frames.append(
            frames[-1]
            if frames
            else np.zeros((224, 224, 3), dtype=np.uint8)
        )
    return np.stack(frames[:num_frames], axis=0)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--model_name", type=str,
        default="MCG-NJU/videomae-base"
    )
    parser.add_argument("--video_dir", type=str, required=True)
    parser.add_argument("--output", type=str, required=True)
    parser.add_argument("--num_frames", type=int, default=16)
    parser.add_argument("--target_frames", type=int, default=50)
    parser.add_argument("--device", type=str, default="cuda")
    args = parser.parse_args()

    device = torch.device(
        args.device if torch.cuda.is_available() else "cpu"
    )

    print(f"Loading {args.model_name}...")
    processor = VideoMAEImageProcessor.from_pretrained(
        args.model_name
    )
    model = VideoMAEModel.from_pretrained(args.model_name).to(device)
    model.eval()

    video_files = sorted([
        f for f in os.listdir(args.video_dir)
        if f.endswith(('.mp4', '.avi', '.mov', '.mkv'))
    ])
    print(f"Found {len(video_files)} videos")

    hidden_dim = model.config.hidden_size
    all_features = []
    for video_file in tqdm(video_files):
        video_path = os.path.join(args.video_dir, video_file)
        try:
            frames = extract_video_frames(
                video_path, args.num_frames
            )
            # VideoMAE 输入: list of PIL Images
            pil_frames = [
                Image.fromarray(f) for f in frames
            ]
            inputs = processor(
                images=pil_frames, return_tensors="pt"
            ).to(device)
            # pixel_values: (1, num_frames, 3, 224, 224)

            with torch.no_grad():
                outputs = model(**inputs)
                # last_hidden_state: (1, N_patches+1, 768)
                # 取 CLS token 或 mean pool
                hidden = outputs.last_hidden_state
                # mean pool over patches (exclude CLS)
                feat = hidden[:, 1:, :].mean(dim=1)  # (1, 768)

            # 扩展到 target_frames
            feat = feat.unsqueeze(1).expand(
                -1, args.target_frames, -1
            )  # (1, 50, 768)
            all_features.append(
                feat.squeeze(0).cpu().numpy()
            )
        except Exception as e:
            print(f"Error processing {video_file}: {e}")
            all_features.append(
                np.zeros(
                    (args.target_frames, hidden_dim),
                    dtype=np.float32
                )
            )

    features_array = np.stack(all_features, axis=0)  # (N, T, D)
    print(f"Extracted features shape: {features_array.shape}")

    with open(args.output, "wb") as f:
        pickle.dump({"vision": features_array}, f)
    print(f"Saved to {args.output}")


if __name__ == "__main__":
    main()
```

### 4.7 补充: 三模态 CHM 扩展设计 ★ 从双模态到三模态

> CAGMamba 是 T+A 双模态模型。Coupled-BI-Mamba3 是 T+A+V 三模态模型。视频模态引入后，融合架构需要重新设计。

#### 4.7.1 问题：视频如何融入 CAGMamba 风格的双模态框架？

CAGMamba 的 CHM 层设计为 `text_features + audio_features + context` 双模态交互。加入视频后，有 **三种扩展策略**：

```
策略 A: 对称三模态 CHM（推荐）
  ┌──────────────────────────────────────────────┐
  │  CoupledMamba3Fork (改造后, 三模态对称)      │
  │                                              │
  │  Audio ──→ Q_A ← K/V 来自 V+L               │
  │  Visual ─→ Q_V ← K/V 来自 A+L               │
  │  Lexical ─→ Q_L ← K/V 来自 A+V               │
  │                                              │
  │  ★ 三模态对称交互, 6 个跨模态方向            │
  │  ★ 复用 CoupledMamba3Fork 的现有设计          │
  │  ★ 视频作为平等模态参与融合                   │
  └──────────────────────────────────────────────┘

策略 B: 文本中心 CHM
  ┌──────────────────────────────────────────────┐
  │  Text 为主, Audio/Video 为辅助               │
  │                                              │
  │  Text ──→ Q_T ← K/V 来自 A+V                │
  │  Audio ─→ Q_A ← K/V 来自 T (仅文本)          │
  │  Video ─→ Q_V ← K/V 来自 T (仅文本)          │
  │                                              │
  │  ★ 文本作为信息枢纽, 避免低质量视频污染       │
  │  ★ 适合视频特征质量不确定的场景               │
  └──────────────────────────────────────────────┘

策略 C: 两阶段融合
  ┌──────────────────────────────────────────────┐
  │  阶段1: T+A 双模态融合 (CAGMamba CHM)        │
  │  阶段2: (T+A) + V 三模态融合                  │
  │                                              │
  │  ★ 渐进式融合, 可逐阶段消融                   │
  │  ★ 适合视频特征与文本/音频语义差距大的场景    │
  └──────────────────────────────────────────────┘
```

### 5.4 模型改造: ContextAwareMSAClassifier

**新建文件**: `coupled_BI_Mamba3/models/classifier_context.py`

```python
"""
ContextAwareMSAClassifier: 带对话上下文的多模态情感识别模型

继承 MSAClassifier, 新增 _encode_with_context 方法:
    1. 分别编码 context 和 main utterance
    2. 池化为特征向量 (B, d_model)
    3. 构建对话序列 [context_pooled, main_pooled] → CoupledMamba3Fork
    4. SSM 状态在 t=0→1 间自动携带上下文信息

数据流:
    context_T/A/V  → 编码 → Pool → c_feat  ┐
    main_T/A/V     → 编码 → Pool → m_feat  ├→ stack([c,m])
                                           ↓
                              CoupledMamba3Fork (L=2)
                                           ↓
                                   取 t=1 → Classifier
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Optional, Tuple, Dict

from .classifier import MSAClassifier


class ContextAwareMSAClassifier(MSAClassifier):
    """
    在 MSAClassifier 基础上增加对话上下文支持.
    """

    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self.use_context = True

    def _encode_single(
        self, text, audio, video,
        audio_lengths=None, vision_lengths=None,
        cu_seqlens=None,
    ) -> Tuple[torch.Tensor, ...]:
        """编码单个话语, 返回三模态池化表征."""
        out_l, out_a, out_v = self._encode(
            text, audio, video,
            audio_lengths=audio_lengths,
            vision_lengths=vision_lengths,
            cu_seqlens=cu_seqlens,
        )
        pl = self._pool(out_l)
        pa = self._pool(out_a)
        pv = self._pool(out_v)
        return pl, pa, pv

    def _encode_with_context(
        self,
        text, audio, video,
        context_text, context_audio, context_video,
        audio_lengths=None, vision_lengths=None,
        cu_seqlens=None,
    ) -> Tuple[torch.Tensor, ...]:
        """
        编码 context + main, 构建对话级序列 [context, main].

        Returns:
            out_l, out_a, out_v: (B, d_model)
            每个模态的 dim=0 位置是从 t=1 (main) 提取的表征,
            已融合 t=0 (context) 的 SSM 状态信息.
        """
        # 1) 编码 context → Pool
        c_l, c_a, c_v = self._encode_single(
            context_text, context_audio, context_video,
            audio_lengths, vision_lengths,
        )
        # 2) 编码 main → Pool
        m_l, m_a, m_v = self._encode_single(
            text, audio, video,
            audio_lengths, vision_lengths,
        )
        # 3) 构建对话序列: stack([context, main], dim=1)
        #    三模态各自: (B, 2, d_model)
        out_l = torch.stack([c_l, m_l], dim=1)
        out_a = torch.stack([c_a, m_a], dim=1)
        out_v = torch.stack([c_v, m_v], dim=1)

        # 4) CoupledMamba3Fork 对话级跨模态融合
        #    SSM 状态在 t=0→1 自动传递上下文信息
        for layer in self.layers:
            out_a, out_v, out_l = layer(
                out_a, out_v, out_l, cu_seqlens=cu_seqlens
            )

        # 5) ★ 取 t=1 (main) 位置的输出
        #    Mamba SSM 状态已携带 t=0 的上下文信息
        out_l = out_l[:, 1, :]  # (B, d_model)
        out_a = out_a[:, 1, :]
        out_v = out_v[:, 1, :]

        return out_l, out_a, out_v

    def forward(
        self,
        text, audio, video,
        context_text=None, context_audio=None,
        context_video=None,
        audio_lengths=None, vision_lengths=None,
        cu_seqlens=None,
    ):
        """
        前向传播. 如果提供了 context, 走上下文融合路径;
        否则回退到原始单话语路径.
        """
        has_context = all(x is not None for x in [
            context_text, context_audio, context_video
        ])

        if has_context:
            # ===== 上下文路径 =====
            if self.use_sub_loss:
                # TODO: 扩展 _encode_with_context 支持 return_ism_cls
                pass
            out_l, out_a, out_v = self._encode_with_context(
                text, audio, video,
                context_text, context_audio, context_video,
                audio_lengths, vision_lengths, cu_seqlens,
            )
        else:
            # ===== 回退: 原始单话语路径 =====
            if self.use_sub_loss:
                out_l, out_a, out_v, c_t, c_a, c_v = self._encode(
                    text, audio, video, cu_seqlens,
                    return_ism_cls=True,
                    audio_lengths=audio_lengths,
                    vision_lengths=vision_lengths,
                )
            else:
                out_l, out_a, out_v = self._encode(
                    text, audio, video, cu_seqlens,
                    audio_lengths=audio_lengths,
                    vision_lengths=vision_lengths,
                )
                c_t = c_a = c_v = None

            out_l = self._pool(out_l)
            out_a = self._pool(out_a)
            out_v = self._pool(out_v)

        # 分类
        fused = self.fusion_norm(
            torch.cat([out_l, out_a, out_v], dim=-1)
        )
        logits = self.head(fused)

        if not self.use_sub_loss:
            return logits

        out = {"logits": logits}
        if self.use_sub_loss and not has_context:
            out["sub_T"] = self.sub_fc_T(c_t)
            out["sub_A"] = self.sub_fc_A(c_a)
            out["sub_V"] = self.sub_fc_V(c_v)
        return out
```

### 5.5 补充: 双向上下文处理 ★ CAGMamba 杀手锏

> CAGMamba 不仅用 context 增强 main，还**反向**用 main 增强 context。两种增强后的表征**同时进入最终融合层**。这是当前方案中缺失的关键设计。

#### 5.5.1 CAGMamba 的双向处理原文

```python
# CAGMamba: msamba_mmml_model.py::forward()
# ===== 正向: main 在 context 条件下被 CHM 增强 =====
text_enhanced = text_pooler
audio_enhanced = audio_pooler
for chm_layer in self.chm_layers:
    text_enhanced, audio_enhanced = chm_layer(
        text_enhanced, audio_enhanced,
        text_context_features=text_context_pooler,   # context → main
        audio_context_features=audio_context_pooler

# ===== ★ 反向: context 在 main 条件下也被 CHM 增强 =====
text_context_enhanced = text_context_pooler
audio_context_enhanced = audio_context_pooler
for chm_layer in self.chm_layers:
    text_context_enhanced, audio_context_enhanced = chm_layer(
        text_context_enhanced, audio_context_enhanced,

        audio_context_features=audio_pooler

    text_context_enhanced,   # context (含 main 信息) ← 反向增强
    audio_context_enhanced
```

#### 5.5.2 改造后的 ContextAwareMSAClassifier 应补充

```python
def _encode_with_context_bidirectional(
    self,
    text, audio, video,
    context_text, context_audio, context_video,
    audio_lengths=None, vision_lengths=None,
):
    """
    双向上下文编码:
    - 正向: main 在 context 条件下跨模态融合
    - ★ 反向: context 在 main 条件下跨模态融合
    - 两路输出同时参与最终分类
    """
    # 1) 编码 context / main → Pool
    c_l, c_a, c_v = self._encode_single(...)
    m_l, m_a, m_v = self._encode_single(...)

    # 2) ★ 正向: [context, main] → 取 t=1 (main)
    fwd_l = torch.stack([c_l, m_l], dim=1)
    fwd_a = torch.stack([c_a, m_a], dim=1)
    fwd_v = torch.stack([c_v, m_v], dim=1)
    for layer in self.layers:
        fwd_a, fwd_v, fwd_l = layer(fwd_a, fwd_v, fwd_l)
    fwd_l, fwd_a, fwd_v = fwd_l[:, 1], fwd_a[:, 1], fwd_v[:, 1]

    # 3) ★ 反向: [main, context] → 取 t=1 (context, 但以 main 为条件)
    rev_l = torch.stack([m_l, c_l], dim=1)
    rev_a = torch.stack([m_a, c_a], dim=1)
    rev_v = torch.stack([m_v, c_v], dim=1)
    for layer in self.layers:
        rev_a, rev_v, rev_l = layer(rev_a, rev_v, rev_l)
    rev_l, rev_a, rev_v = rev_l[:, 1], rev_a[:, 1], rev_v[:, 1]

    # 4) ★ 双向表征拼接 → 分类
    return (
        torch.cat([fwd_l, rev_l], dim=-1),  # (B, 2*d_model)
        torch.cat([fwd_a, rev_a], dim=-1),
        torch.cat([fwd_v, rev_v], dim=-1),
    )
```

### 6.1 改造前架构

```
│                                                  │
│  H = SSM(Q, K, V)  → out_proj(H)                │
│  out = LN(H + u_tgt)           残差连接          │

│  问题: 源模态噪声直接污染 V, 无保护机制           │
```

### 6.2 改造后架构

```
┌──────────────────────────────────────────────────┐
│    改造后: 门控融合 + V/B 自信息保留              │
│                                                  │
│  GatedCrossMamba3Cell 内部:                      │
│                                                  │
│  目标模态 tgt (如 Audio):                         │
│    Q=C ← c_proj_tgt(u_tgt)         来自自身      │
│                                                  │
│    ★ V 通道: 混合自信息 + 跨模态                  │
│    V_self = v_projs[tgt](u_tgt)    tgt 自身 V    │
│    V_cross = w0·V_src0 + w1·V_src1               │
│    V = λ·V_self + (1-λ)·V_cross   λ=v_self_ratio │
│    ★ 保留 tgt 模态的 V 锚点!                     │
│                                                  │
│    ★ B 通道: 同样混合自信息和跨模态              │
│    B = μ·B_self + (1-μ)·B_cross                  │
│                                                  │

│                                                  │
│  ★ 显式门控 (新增, 参考 CAGMamba):               │
│  gate = σ(gate_proj(concat(u_tgt, cross_out)))   │
│  out = u_tgt + gate * cross_out                  │
│  ★ 可学习门控自适应调节跨模态注入强度            │
│                                                  │
│  对比 CAGMamba:                                  │
│  final = unimodal_mamba + σ(gate) * cross_mamba  │
│  ★ 理念一致, 门控位置不同 (SSM 外 vs SSM 外)     │
└──────────────────────────────────────────────────┘
```

### 6.3 代码改造

**修改文件**: `coupled_BI_Mamba3/models/coupled_mamba3_fork.py`

在 `CrossMamba3Cell.__init__` 中添加门控参数：

```python
def __init__(
    self,
    d_model: int,
    # ... 原有参数 ...
    v_self_ratio: float = 0.3,        # ★ 新增
    b_self_ratio: float = 0.1,        # ★ 新增
    use_gate: bool = True,            # ★ 新增
    **kwargs,
):
    # ... 原有初始化 ...
    self.v_self_ratio = float(v_self_ratio)
    self.b_self_ratio = float(b_self_ratio)
    self.use_gate = use_gate

    # ★ 新增: tgt 自身的 V 投影 (用于 V_self)
    self.v_proj_self = nn.Linear(
        d_model, self.d_inner, bias=False, **factory_kwargs
    )
    # ★ 新增: tgt 自身的 B 投影 (用于 B_self)
    d_b = d_state * self.num_bc_heads * self.mimo_rank
    self.b_proj_self = nn.Linear(
        d_model, d_b, bias=False, **factory_kwargs
    )

    # ★ 新增: 门控网络
    if use_gate:
        self.gate_proj = nn.Sequential(
            nn.Linear(2 * d_model, d_model),
            nn.SiLU(),
            nn.Linear(d_model, d_model),
        )
```

在 `CrossMamba3Cell.forward` 中修改 V/B 计算并添加门控：

```python
def forward(self, u_tgt, u_src0, u_src1, w_src, src_keys,
            cu_seqlens=None):
    # ... 1) tgt 出 z + ctrl + C (不变) ...

    # ---------------- 3) ★ V 通道: 混合自信息 + 跨模态 ----------------
    w0, w1 = w_src[..., 0:1], w_src[..., 1:2]

    # V_self: tgt 自身
    V_self = self.v_proj_self(u_tgt)
    # V_cross: 源模态加权
    V0 = self.v_projs[s0_key](u_src0)
    V1 = self.v_projs[s1_key](u_src1)
    V_cross = w0 * V0 + w1 * V1
    # 混合
    V = (self.v_self_ratio * V_self
         + (1.0 - self.v_self_ratio) * V_cross)
    x = rearrange(V, "b l (h p) -> b l h p", p=self.headdim)

    # ---------------- ★ B 通道: 同样混合 ----------------
    B_self = self.b_proj_self(u_tgt)
    B0 = self.b_projs[s0_key](u_src0)
    B1 = self.b_projs[s1_key](u_src1)
    B_cross = w0 * B0 + w1 * B1
    B = (self.b_self_ratio * B_self
         + (1.0 - self.b_self_ratio) * B_cross)
    B = rearrange(B, "b l (r g n) -> b l r g n",
                  r=self.mimo_rank, g=self.num_bc_heads)

    # ... 4-7) SSM kernel + out_proj (不变) ...

    # ---------------- ★ 8) 显式门控 (新增) ----------------
    if self.use_gate:
        gate_input = torch.cat([u_tgt, out], dim=-1)
        gate = torch.sigmoid(self.gate_proj(gate_input))
        # 对齐 CAGMamba: final = self + gate * cross
        out = u_tgt + gate * out
    else:
        out = out  # 在下游 CoupledMamba3Fork 中做残差

    return out
```

### 8.2 8 组参数分组代码（对齐 CAGMamba）

**修改文件**: `coupled_BI_Mamba3/trainer.py`

```python
# ★ 替换原有的 2 组 (BERT vs Other) 为 8 组, 对齐 CAGMamba:

bert_lr = float(getattr(self.args, "bert_learning_rate", 2e-5))
main_lr = float(self.args.learning_rate)
wd = float(self.args.weight_decay)

# ================================================================
# 8 组参数分组 (对齐 CAGMamba 的细粒度分层学习率)
# ================================================================
bert_decay_params = []      # 1) BERT w/ weight decay
bert_nodecay_params = []    # 2) BERT bias/LayerNorm (no decay)
audio_base_params = []      # 3) Data2Vec 浅层 (< 12)
audio_deep_params = []      # 4) Data2Vec 深层 (≥ 12), 更小 lr
mamba_state_params = []     # 5) A_log, D — 状态核心, 极小 wd
mamba_conv_params = []      # 6) conv1d — 局部特征提取
mamba_dt_params = []        # 7) dt_proj — 最敏感参数
mamba_proj_fusion_params = [] # 8) in_proj/out_proj/x_proj + CHM fusion + 其他

for n, p in self.model.named_parameters():
    if not p.requires_grad:
        continue

    # --- BERT/RoBERTa 参数 ---
    if "text_encoder" in n:
        if any(nd in n for nd in ['bias', 'LayerNorm.bias', 'LayerNorm.weight']):
            bert_nodecay_params.append(p)
        else:
            bert_decay_params.append(p)
        continue

    # --- Data2Vec 音频模型参数 (区分浅层/深层) ---
    if "data2vec" in n or "audio_encoder" in n:
        # 检查是否为深层 (层索引 ≥ 12)
        import re
        layer_match = re.search(r'layers\.(\d+)', n)
        if layer_match and int(layer_match.group(1)) >= 12:
            audio_deep_params.append(p)
        else:
            audio_base_params.append(p)
        continue

    # --- Mamba 状态空间核心参数 ---
    if any(k in n for k in ("A_log", ".D")):
        mamba_state_params.append(p)
        continue

    # --- Mamba 卷积参数 ---
    if "conv1d" in n:
        mamba_conv_params.append(p)
        continue

    # --- Mamba dt 参数 (最敏感) ---
    if any(k in n for k in ("dt_proj", "dt_bias")):
        mamba_dt_params.append(p)
        continue

    # --- 投影层 + CHM 融合 + 其他 ---
    mamba_proj_fusion_params.append(p)

# ================================================================
# 构造 8 组优化器参数
# ================================================================
param_groups = []

if bert_decay_params:
    param_groups.append({
        "params": bert_decay_params, "lr": bert_lr,
        "weight_decay": 0.01, "name": "bert_decay",
    })
if bert_nodecay_params:
    param_groups.append({
        "params": bert_nodecay_params, "lr": bert_lr,
        "weight_decay": 0.0, "name": "bert_nodecay",
    })
if audio_base_params:
    param_groups.append({
        "params": audio_base_params,
        "lr": bert_lr * 0.5,          # ★ 5e-6 for base
        "weight_decay": 0.01, "name": "audio_base",
    })
if audio_deep_params:
    param_groups.append({
        "params": audio_deep_params,
        "lr": bert_lr * 0.2,          # ★ 2e-6 for deep layers
        "weight_decay": 0.01, "name": "audio_deep",
    })
if mamba_state_params:
    param_groups.append({
        "params": mamba_state_params,
        "lr": main_lr * 0.5,           # ★ 0.5×
        "weight_decay": 1e-6,          # ★ 极小 wd
        "name": "mamba_state",
    })
if mamba_conv_params:
    param_groups.append({
        "params": mamba_conv_params,
        "lr": main_lr * 0.8,           # ★ 0.8×
        "weight_decay": 1e-4, "name": "mamba_conv",
    })
if mamba_dt_params:
    param_groups.append({
        "params": mamba_dt_params,
        "lr": main_lr * 0.3,           # ★ 0.3× (最敏感)
        "weight_decay": 1e-5, "name": "mamba_dt",
    })
if mamba_proj_fusion_params:
    param_groups.append({
        "params": mamba_proj_fusion_params,
        "lr": main_lr * 1.2,           # ★ 1.2× (加速收敛)
        "weight_decay": 1e-4, "name": "mamba_proj_fusion",
    })

self.optimizer = torch.optim.AdamW(
    param_groups,
    eps=1e-8,           # ★ 稍大的 eps, 提高训练稳定性
    betas=(0.9, 0.999),
)

# 打印分组日志
for g in param_groups:
    self.logger.info(
        f"Param group '{g['name']}': "
        f"{len(g['params'])} params, "
        f"lr={g['lr']:.2e}, wd={g['weight_decay']:.2e}"
    )
```

### 8.3 损失函数对齐：SmoothL1Loss → L1Loss

CAGMamba 使用 **L1Loss（MAE）** 而非 SmoothL1Loss。原因：

- MOSI/MOSEI 的情感标注范围 [-3, +3]，少数样本可能存在标注歧义（极端值）
- L1Loss 对所有误差使用统一的梯度幅度，对离群值更鲁棒
- SmoothL1Loss 在 |error| < 1 时退化为二次方，可能在过渡区过度惩罚

### 9.1 ISM 的角色分析

```
ISM (Intra-modal Sequence Modeling) 角色:
  - 对单模态的 50 帧序列做时序建模 (GLCE + BiMamba)
  - 设计来自 Vision Mamba (处理图像 patch 序列)

  - 音频: Data2Vec 已编码时序上下文 → ISM 基本冗余
  - 视频: CLIP 逐帧独立编码 → ISM 仍有补充时序价值
```

### 9.2 ISM 改造前/后

```
改造前 (ism_depth=3, 默认):

  proj → [BiMamba+GLCE] → 输出
         ↑ 1层, 参数减少 67%
         总计: ~588K ISM 参数

改造后 (ism_depth=0, 极限消融):
  proj → 直接输出 (B, 50, d_model)
```

## Phase 11: Checkpoint 训练与显存优化

> **预期收益**: ★★ (稳定性) | **改动量**: 小 | **独立于其他 Phase**

### 11.1 背景

CAGMamba 通过 `use_checkpoint` 参数支持 **gradient checkpointing**。当同时加载 RoBERTa-large (355M) + Data2Vec-large (313M) + Mamba-3 融合层时，单卡 16GB 显存可能不足。Checkpoint 训练以时间换空间，放弃中间激活的缓存，在反向传播时重新计算。

### 11.2 改造前/后

```
改造前:
  前向: 计算所有激活 → 缓存 → 反向: 直接使用缓存
  显存: ~14GB (RoBERTa-base + Data2Vec-base)
  速度: 正常

改造后 (启用 checkpoint):
  前向: 计算所有激活 → 仅缓存 checkpoint 边界 → 反向: 重新计算中间激活
  显存: ~9GB (RoBERTa-large + Data2Vec-large) — 节省 35%
  速度: 约 1.3× 慢
```

```json
    }
}
```

### 11.4 混合精度训练 (推荐)

```python
# 在 Trainer.__init__ 中添加 AMP 支持:
self.use_amp = bool(getattr(args, "use_amp", False))
self.scaler = torch.cuda.amp.GradScaler() if self.use_amp else None

# 在 train_one_epoch 中:
if self.use_amp:
    with torch.cuda.amp.autocast():
        logits = self._forward_pred(batch)
        loss = self.criterion(logits, label)
    self.scaler.scale(loss).backward()
    self.scaler.step(self.optimizer)
    self.scaler.update()
```

### B.3 训练时 NaN 损失

```bash
# 症状: non-finite loss, skipping batch
# 常见原因 & 解决:
# 1. 学习率过大 → 降低 main_lr 到 5e-5
# 2. 梯度爆炸 → 降低 grad_clip 到 0.3
# 3. ism_depth=3 不稳定 → 降到 ism_depth=1
```
