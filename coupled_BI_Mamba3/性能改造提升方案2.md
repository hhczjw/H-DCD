## 改造全景概览 (v1 → v2)

```
v1 改造后架构 (Phase 1-11):
  RoBERTa + Data2Vec-Audio + CLIP/VideoMAE/OpenFace
       ↓                ↓                ↓
  ISM ×1          ISM ×1          ISM ×1    ← 独立参数 Bi-Mamba
       ↓                ↓                ↓
  CoupledMamba3Fork ×2 (跨模态 Q/K/V 融合)
       ↓
  [Context, Main] Pool → Concat → Classifier

v2 改造后架构 (Phase 12-18):
  RoBERTa + Data2Vec-Audio + CLIP/VideoMAE/OpenFace
       ↓                ↓                ↓
  ★ SA-BSSM ×1    SA-BSSM ×1    SA-BSSM ×1    ← A 矩阵跨模态共享
       ↓                ↓                ↓
  ★ Cross-Attention (渐进融合: 局部→全局)
       ↓                ↓                ↓
  CoupledMamba3Fork ×2
       ↓                ↓                ↓
  ★ MEM ×1 (Bi-Mamba + FFN 精炼)
       ↓                ↓                ↓
  ★ MDL (KL 散度 → 异构性得分 → 门控加权)
       ↓
  ★ Gated Feature Aggregation → Classifier
  [Context 双向: context↔main 互相增强]
```

### v1 → v2 核心变化

| 组件 | v1 | v2 | 来源 |
|------|-----|-----|------|
| ISM 参数 | 三模态独立 A/B/C | **A 共享**, B/C 独立 | MPFEN SA-BSSM |
| 跨模态路径 | 直接 CoupledMamba | **Bi-Mamba → Cross-Attn → Fusion** | MPFEN MPFL |
| 融合后处理 | 无 | **MEM (Bi-Mamba+FFN)** | MPFEN MEM |
| 模态差异 | 忽略 | **KL 散度门控** | MPFEN MDL |
| 特征聚合 | Mean Pool + Concat | **Gating × score 加权** | MPFEN Gating |
| 上下文 | 单向 context→main | **双向 context↔main** | CAGMamba CHM |

## Phase 12: 共享状态空间双向 Mamba (SA-BSSM)

> **预期收益**: ★★★ | **改动量**: 小 | **依赖**: 无 | **来源**: MPFEN 公式 (1)(2)

### 12.1 改造前架构

```
三模态 ISM (各模态独立参数):
  ISMText  (A_t, B_t, C_t)
  ISMAudio (A_a, B_a, C_a)    ← 所有参数完全独立, 无共享
  ISMVideo (A_v, B_v, C_v)
```

### 12.2 改造后架构

```
共享状态空间 ISM:
  SA-BSSM (A_shared, B_t, C_t)    ← A 矩阵三模态共享
  SA-BSSM (A_shared, B_a, C_a)    ← 同一状态空间对齐
  SA-BSSM (A_shared, B_v, C_v)    ← 减少参数, 促进跨模态一致性
```

**设计思想**: SSM 的状态转移矩阵 $A$ 决定了系统如何随时间演化。如果三个模态的 $A$ 共享，它们就在**同一个状态空间中**进化，自然实现了隐式的跨模态对齐，而不需要显式的 cross-attention。

### 12.3 公式

$$h_{m,t} = A_{shared} \cdot h_{m,t-1} + B_m \cdot x_{m,t}, \quad y_{m,t} = C_m \cdot h_{m,t}$$

- $A_{shared} \in \mathbb{R}^{d\_state \times d\_state}$ — 三模态共享的系统矩阵
- $B_m \in \mathbb{R}^{d\_state \times d\_model}$ — 模态特有输入投影
- $C_m \in \mathbb{R}^{d\_model \times d\_state}$ — 模态特有输出投影

## Phase 13: 模态差异学习 (MDL)

> **预期收益**: ★★★★★ | **改动量**: 中等 | **依赖**: 无 | **来源**: MPFEN 公式 (12)(13)(14)

### 13.1 改造前架构

```
ISM 输出 → Pool → Concat → Classifier
         ↑ 无模态差异评估, 直接拼接
```

### 13.2 改造后架构

```
ISM 输出 → Pool
    ↓
┌───────────────────────────────────────────┐
│              MDL 模块                       │
│                                           │
│  x_t → VAE_t → q(z_t|x_t) ─┐             │
│  x_a → VAE_a → q(z_a|x_a) ─┤ KL 散度     │
│  x_v → VAE_v → q(z_v|x_v) ─┘ ↓           │
│                           score ∈ [0,1]    │
│                               ↓           │
│  fused × score  +  unimodal × (1-score)   │
│                               ↓           │
│  Gating → 加权聚合 → 最终特征              │
└───────────────────────────────────────────┘
```

**设计思想**: 当模态间情感线索一致时（如文本说"I'm happy"且音频语调上扬），$D_{KL}$ 小 → score→1 → 依赖融合特征。当模态冲突时（如讽刺场景），$D_{KL}$ 大 → score→0 → 退回到单模态特征，防止融合被噪声污染。

### 13.3 公式

**VAE 后验分布** — 公式 (12):

$$q(z_m | x_m) = \mathcal{N}(z_m | \mu(x_m), \sigma(x_m)), \quad m \in \{t, a, v\}$$

**异构性得分** — 公式 (13):

$$score = \sigma\left(\frac{1}{6}\sum_{i\neq j} D_{KL}(q(z_i|x_i) \parallel q(z_j|x_j))\right)$$

其中 $D_{KL}(P \parallel Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$

**特征加权** — 公式 (14):

$$\bar{x}_{e,m} = \text{Gate}(\text{Pool}(x_{e,m})) \cdot \text{Pool}(x_{e,m}) \cdot score$$

$$\bar{x}_m = \text{Pool}(x_m) \cdot (1 - score)$$

$$f = \text{Concat}(\bar{x}_t, \bar{x}_a, \bar{x}_v, \bar{x}_{e,t}, \bar{x}_{e,a}, \bar{x}_{e,v})$$

### 13.4 代码改造

**新建文件**: `models/mdl.py`

```python
"""
Modality Discrepancy Learning (MDL)
====================================
来源: MPFEN (Qin et al., ESWA 2026)

通过 VAE + KL 散度度量模态间异构性, 动态调整融合特征与单模态特征的权重。
"""

import torch
import torch.nn as nn
import torch.nn.functional as F


class VAEEncoder(nn.Module):
    """单模态 VAE 编码器: x → (mu, logvar)"""

    def __init__(self, input_dim: int, latent_dim: int = 64):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, input_dim // 2),
            nn.ReLU(),
            nn.Linear(input_dim // 2, latent_dim * 2),  # mu + logvar
        )

    def forward(self, x: torch.Tensor):
        # x: (B, d_model) 已池化
        h = self.encoder(x)
        mu, logvar = h.chunk(2, dim=-1)
        return mu, logvar


def kl_divergence(mu1, logvar1, mu2, logvar2) -> torch.Tensor:
    """两个高斯分布之间的 KL 散度: D_KL(N1 || N2)"""
    return 0.5 * torch.sum(
        logvar2 - logvar1 - 1 +
        logvar1.exp() / logvar2.exp() +
        (mu1 - mu2).pow(2) / logvar2.exp(),
        dim=-1
    ).mean()


class ModalityDiscrepancyLearning(nn.Module):
    """
    模态差异学习模块.

    Args:
        d_model: 单模态池化后的特征维度
        latent_dim: VAE 隐空间维度
    """

    def __init__(self, d_model: int = 128, latent_dim: int = 64):
        super().__init__()
        self.vae_t = VAEEncoder(d_model, latent_dim)
        self.vae_a = VAEEncoder(d_model, latent_dim)
        self.vae_v = VAEEncoder(d_model, latent_dim)

        # 门控网络: 对融合特征做自适应权重
        self.gate_t = nn.Sequential(
            nn.Linear(d_model, d_model // 4),
            nn.ReLU(),
            nn.Linear(d_model // 4, d_model),
            nn.Sigmoid(),
        )
        self.gate_a = nn.Sequential(
            nn.Linear(d_model, d_model // 4),
            nn.ReLU(),
            nn.Linear(d_model // 4, d_model),
            nn.Sigmoid(),
        )
        self.gate_v = nn.Sequential(
            nn.Linear(d_model, d_model // 4),
            nn.ReLU(),
            nn.Linear(d_model // 4, d_model),
            nn.Sigmoid(),
        )

    def forward(
        self,
        uni_t: torch.Tensor,   # (B, d_model) 单模态池化特征
        uni_a: torch.Tensor,
        uni_v: torch.Tensor,
        fused_t: torch.Tensor,  # (B, d_model) 融合后特征
        fused_a: torch.Tensor,
        fused_v: torch.Tensor,
    ) -> torch.Tensor:
        """
        Returns:
            final_feat: (B, 6 * d_model) 加权聚合后的特征
        """
        # 1) VAE 编码 → (mu, logvar)
        mu_t, lv_t = self.vae_t(uni_t)
        mu_a, lv_a = self.vae_a(uni_a)
        mu_v, lv_v = self.vae_v(uni_v)

        # 2) 成对 KL 散度 → 异构性得分
        kl_sum = (
            kl_divergence(mu_t, lv_t, mu_a, lv_a) +
            kl_divergence(mu_a, lv_a, mu_t, lv_t) +
            kl_divergence(mu_t, lv_t, mu_v, lv_v) +
            kl_divergence(mu_v, lv_v, mu_t, lv_t) +
            kl_divergence(mu_a, lv_a, mu_v, lv_v) +
            kl_divergence(mu_v, lv_v, mu_a, lv_a)
        )
        score = torch.sigmoid(kl_sum / 6.0)  # (B,) → (B, 1)
        score = score.unsqueeze(-1)           # (B, 1)

        # 3) 门控加权
        fused_t_w = self.gate_t(fused_t) * fused_t * score
        fused_a_w = self.gate_a(fused_a) * fused_a * score
        fused_v_w = self.gate_v(fused_v) * fused_v * score

        uni_t_w = uni_t * (1 - score)
        uni_a_w = uni_a * (1 - score)
        uni_v_w = uni_v * (1 - score)

        # 4) 拼接 6 路特征
        return torch.cat([
            uni_t_w, uni_a_w, uni_v_w,
            fused_t_w, fused_a_w, fused_v_w,
        ], dim=-1)
```

**修改文件**: `models/classifier.py`

```python
class MSAClassifier(nn.Module):
    def __init__(self, ..., use_mdl: bool = False):
        ...
        if use_mdl:
            self.mdl = ModalityDiscrepancyLearning(d_model=d_model)
            fused_dim = 6 * d_model  # 3 单模态 + 3 融合
        else:
            self.mdl = None
            fused_dim = 3 * d_model

    def forward(self, ...):
        ...
        # 池化
        pl = self._pool(out_l)
        pa = self._pool(out_a)
        pv = self._pool(out_v)

        if self.mdl is not None:
            # ★ MDL 路径

                uni_t=pl, uni_a=pa, uni_v=pv,

        logits = self.head(fused)
        return logits
```

## Phase 14: 渐进式跨模态融合 (Progressive Fusion)

> **预期收益**: ★★★★ | **改动量**: 中等 | **依赖**: Phase 12 | **来源**: MPFEN 公式 (3)-(7)

### 14.1 改造前架构

```
ISM 输出 → CoupledMamba3Fork (直接跨模态 Q/K/V 融合)
              ↑ 一步到位, 无渐进对齐
```

### 14.2 改造后架构

```
ISM 输出 (经过 SA-BSSM 对齐)
       ↓
┌──────────────────────────────────────────┐
│          MPFL (渐进融合层) × N             │
│                                          │
│  Step 1: SA-BSSM (局部细粒度对齐)         │
│     ↓                                    │
│  Step 2: Cross-Attention (全局语义交互)   │
│     ↓                                    │
│  Step 3: Fusion Enhancement Block         │
│     (Concat → Proj → FFN → Residual)     │
│     ↓                                    │
│  Output: 以每个模态为中心的三路融合特征    │
└──────────────────────────────────────────┘
       ↓
  CoupledMamba3Fork (深度跨模态交互)
```

### 14.3 公式

**Cross-Attention** (以音频→文本为例):

$$x_{a \to t} = \text{softmax}\left(\frac{(x_t W_Q)(x_a W_K)^\top}{\sqrt{d_k}}\right)(x_a W_V)$$

**Fusion Enhancement Block** — 公式 (6):

$$x_t^{out} = \text{FEB}(\text{Proj}(\text{Concat}(x_t, x_{a \to t}, x_{v \to t})))$$

其中 FEB = LayerNorm → FFN → Residual

### 14.4 代码改造

**新建文件**: `layers/mpfl.py`

```python
"""
Multimodal Progressive Fusion Layer (MPFL)
===========================================
来源: MPFEN (Qin et al., ESWA 2026)

渐进式跨模态对齐: SA-BSSM (局部) → Cross-Attn (全局) → FEB (增强)
"""

import torch
import torch.nn as nn
import torch.nn.functional as F


class CrossModalAttention(nn.Module):
    """Cross-Attention: Q 来自 anchor, K/V 来自 auxiliary"""

    def __init__(self, d_model: int, n_heads: int = 8):
        super().__init__()
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        self.W_O = nn.Linear(d_model, d_model)

    def forward(self, anchor, auxiliary):
        B, L, D = anchor.shape
        Q = self.W_Q(anchor).view(B, L, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_K(auxiliary).view(B, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_V(auxiliary).view(B, -1, self.n_heads, self.d_k).transpose(1, 2)

        attn = torch.softmax(Q @ K.transpose(-2, -1) / (self.d_k ** 0.5), dim=-1)
        out = (attn @ V).transpose(1, 2).reshape(B, L, D)
        return self.W_O(out)


class FusionEnhancementBlock(nn.Module):
    """FEB: Concat → Proj → FFN → Residual"""

    def __init__(self, d_model: int, d_ff: int = None):
        super().__init__()
        d_ff = d_ff or d_model * 4
        self.proj = nn.Linear(3 * d_model, d_model)
        self.norm = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Linear(d_ff, d_model),
        )

    def forward(self, x_anchor, x_aux1, x_aux2):
        fused = self.proj(torch.cat([x_anchor, x_aux1, x_aux2], dim=-1))
        return self.norm(fused + self.ffn(fused))


class MPFLayer(nn.Module):
    """
    单个渐进融合层。
    以 text 为中心时: audio→text, video→text → FEB → 输出
    """

    def __init__(self, d_model: int, n_heads: int = 8, use_sa_bssm: bool = True):
        super().__init__()
        self.cross_attn_a2t = CrossModalAttention(d_model, n_heads)
        self.cross_attn_v2t = CrossModalAttention(d_model, n_heads)
        self.feb = FusionEnhancementBlock(d_model)
        # SA-BSSM 复用 ISM 层, 此处略

    def forward(self, x_t, x_a, x_v):
        # 以 text 为中心
        a2t = self.cross_attn_a2t(x_t, x_a)
        v2t = self.cross_attn_v2t(x_t, x_v)
        x_t_out = self.feb(x_t, a2t, v2t)
        return x_t_out
```

### 14.5 预期效果

- 局部+全局双阶段对齐, 比直接 Cross-Attn 更精细
- 参数量: 每层约 `3 × 4 × d_model²` (~200K for d_model=128)
- 可与现有 CoupledMamba3Fork 叠加使用

## Phase 16: 门控特征聚合 (Gated Feature Aggregation)

> **预期收益**: ★★★ | **改动量**: 小 | **依赖**: 无 | **来源**: MPFEN 公式 (14)

### 16.1 改造前

```python
pl = mean_pool(out_l)
```

### 16.2 改造后

```python
pl = mean_pool(out_l)
pa = mean_pool(out_a)
pv = mean_pool(out_v)

# ★ Gating: 自适应选择有效信息
gate_l = sigmoid(linear_l(pl))
gate_a = sigmoid(linear_a(pa))
gate_v = sigmoid(linear_v(pv))

pl_g = pl * gate_l
pa_g = pa * gate_a
pv_g = pv * gate_v

fused = concat([pl_g, pa_g, pv_g])
logits = head(fused)
```

### 16.3 预期效果

- 抑制噪声模态的贡献 (如 MOSI 中低质量视频帧)
- 仅增加 3 × d_model 个参数 (~1K)

## Phase 17: 双向上下文精炼

> **预期收益**: ★★★★ | **改动量**: 中等 | **依赖**: Phase 5 | **来源**: CAGMamba CHM + MPFEN Context

### 17.1 改造前 (Phase 5)

```
context → ISM → Pool → [c, m] → CoupledMamba → 取 t=1
                                        ↑ 仅 context→main 单向
```

### 17.2 改造后

```
context → ISM → Pool ─┐
main    → ISM → Pool ─┤
                       ├→ [c, m] → CoupledMamba → 取 t=1 (main增强)
                       ├→ [m, c] → CoupledMamba → 取 t=1 (context增强)
                       ↓
                  Concat(main增强, context增强) → Classifier
```

**设计思想**: CAGMamba 发现不仅 context 增强 main 有用, **反向**用 main 增强 context 也能提供额外信息——因为当前话语的情感可以反向解释前一句的歧义。

### 17.3 代码修改

参考 `context_fusion.py`, 增加反向融合分支。
