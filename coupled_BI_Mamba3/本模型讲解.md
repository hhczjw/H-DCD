# Coupled-BI-Mamba3 模型架构分析

---

## 1. 整体架构概述

**Coupled-BI-Mamba3** 是一个面向多模态情感识别（Text / Audio / Vision）的深度学习模型。其核心设计思路是：**以 Mamba-3 状态空间模型（SSM）为骨干，通过跨模态的 B/C 参数注入机制，实现三模态之间的双向耦合状态空间融合**。

整体拓扑结构为「串行-分叉」式（Serial-Fork）流水线：

```
T/A/V 原始特征
  → BERT编码 + 线性投影
  → ISMEncoder × ism_depth    （单模态序列建模）
  → CoupledMamba3Fork × num_layers  （跨模态双向SSM融合）
  → Mean池化 → 拼接 → 分类头
```

模型自上而下分为四大阶段：

1. **输入投影阶段**：将不同维度的三模态原始特征统一投影到 `d_model` 维空间
2. **ISM 单模态序列建模阶段**：每个模态独立经过 ISMEncoder（GLCE + BiMamba SSM），提取模态内时序特征
3. **跨模态耦合融合阶段**：堆叠多层 `CoupledMamba3Fork`，每层内三个 `CrossMamba3Cell` 分别以某一模态为目标，从其余两模态注入 B（Key）和 V（Value）信息
4. **输出阶段**：Mean 池化 + 拼接 + MLP 分类/回归头

该模型的设计哲学是 **「目标主导控制，源提供内容」**——目标模态决定 SSM 的衰减动力学（A/Δ）、旋转编码（RoPE angles）和读出（C/Q），源模态负责注入可写入的状态内容（B/K 和 V/x），精确对齐了 Cross-Attention 的语义。

## 2. 模块组成与功能

### 2.1 输入层：特征投影与序列对齐

**组成模块**：`BertTextEncoder` + `nn.Linear` 投影层 + `adaptive_avg_pool1d` 序列对齐

| 组件 | 功能 |
|------|------|
| `BertTextEncoder` | 接收 `(B, 3, L)` 的 BERT 输入（input_ids / attention_mask / token_type_ids），输出 `(B, L, 768)` 文本隐状态；支持 HuggingFace BERT 加载失败时回退到 `nn.Embedding` |
| `proj_text / proj_audio / proj_video` | 三个独立的 `nn.Linear(in_dim, d_model)` 线性层，将文本(768)、音频、视频特征分别投影到统一的 `d_model` 维度 |
| `adaptive_avg_pool1d` | 将音频/视频序列长度自适应对齐到文本序列长度 `Lt`，确保三模态维度一致 `(B, L, d_model)` |

### 2.2 ISM 单模态序列建模层

**组成模块**：`ISMEncoder` = CLS Token + 可学习位置编码 + `Block_GLCE × depth`

这是对齐 **MSAmba**（Vim 论文）的单模态序列建模模块，三模态各持一套**独立权重**的 ISMEncoder。

**`Block_GLCE` 内部结构**（对齐 MSAmba 原版）：

```
Input (hidden_states, residual)
  ↓
fused_add_norm (RMSNorm + 残差融合, Triton 实现)
  ↓
GLCE: global_extractor(Linear) + local_extractor(Conv1d) + shortcut
  ↓
fused_add_norm (第二个 LayerNorm, 后归一化)
  ↓
BiMamba SSM (双向状态空间模型)
  ↓
(hidden_states, residual) 双流残差输出
```

关键特性：

- **双流残差传递**：`(hidden_states, residual)` 跨层传递，对齐 MSAmba
- **GLCE（Global-Local Context Extraction）**：`Linear(seq_len → seq_len)` 捕获全局上下文 + `Conv1d(kernel_size=3)` 捕获局部上下文
- **CLS Token + 可学习位置编码**：GPT-2 风格 `trunc_normal_` 初始化
- **Pad Mask 感知**：在每个 Block_GLCE 之后对 padding 位置做 zero-out，防止污染下游
- 支持两种 **mixer 类型**切换：
  - `"bimamba"`：基于 Mamba-2 的 `Mamba(bimamba_type="v2")`，d_state 默认 16
  - `"bimamba3"`：基于 Mamba-3 的 `BiMamba3`，d_state 默认 128

### 2.3 跨模态耦合融合层（核心模块）

**组成模块**：`CoupledMamba3Fork`（每层包含 3 个 `CrossMamba3Cell`）

这是整个模型的 **核心创新模块**。每层 `CoupledMamba3Fork` 内部结构：

```
输入: x_audio, x_visual, x_lexical  (B, L, d_model)
                    ↓
    ┌───────────────┼───────────────┐
    ↓               ↓               ↓
CrossMamba3Cell   CrossMamba3Cell   CrossMamba3Cell
 (tgt=audio)      (tgt=visual)     (tgt=lexical)
    ↓               ↓               ↓
 残差 + LN       残差 + LN         残差 + LN
    ↓               ↓               ↓
out_audio        out_visual        out_lexical
```

**`CrossMamba3Cell`（跨模态 Mamba-3 单元）** 是直接 fork 自官方 `Mamba3` 类的最小侵入改造版本，完整保留了 Mamba-3 的所有工程特性。

**`CrossMamba3Cell` 内部投影分解**：

| 投影 | 来源 | 语义 |
|------|------|------|
| `in_proj_tgt` → z, x_default, dd_dt, dd_A, trap, angles | **目标模态** | SSM 的控制信号：门控 z、默认 V 锚、离散化步长 Δ、状态矩阵 A、Trapezoidal 权重、RoPE 旋转角 |
| `c_proj_tgt` → C | **目标模态** | SSM 的读出矩阵 C（类比 Attention 的 Query） |
| `b_projs[src]` → B | **两个源模态**（加权融合） | SSM 的写入矩阵 B（类比 Attention 的 Key） |
| `v_projs[src]` → V/x | **两个源模态**（加权融合） | SSM 的输入值 V（类比 Attention 的 Value） |

**动态源权重网络**（`weight_net`）：

```python
w_logits = Linear(d_model*3 → d_model) → Tanh → Linear(d_model → 2)
w_src = softmax(w_logits)  # (B, L, 2)，对两个源模态的动态加权
```

该网络以 `[u_tgt, u_src0, u_src1]` 拼接为输入，**自适应学习每个时间步、每个样本上两个源模态的相对重要性**。

**`v_self_ratio` 机制**：引入目标模态自身的 V 锚点，通过凸组合 `x = v_self_ratio * x_default + (1 - v_self_ratio) * x_src_weighted`，防止源模态含噪时带偏目标模态。

### 2.4 输出层

**组成模块**：Mean 池化 + LayerNorm + MLP 头

```python
fused = LayerNorm(concat([pool(out_l), pool(out_a), pool(out_v)]))
logits = Linear(d_model) → GELU → Dropout → Linear(num_classes)
```

- 支持 `pool_type` 切换：`"mean"`（Mask 感知平均）/ `"last"` / `"cls"`
- 回归任务（MOSI/MOSEI）：`num_classes=1`
- 分类任务（IEMOCAP 4 类 / MELD 7 类）：`num_classes=K`
- 可选的多任务 **sub_loss 分支**（SIMS 数据集）：从 ISM 的 CLS token 分别预测 T/A/V 子分数，提供辅助监督信号

## 3. 核心技术解析

### 3.1 双向 Mamba（BiMamba）机制

模型在 **两个层次** 上使用了双向 SSM：

| 层次 | 实现 | 双向方式 |
|------|------|----------|
| **ISM 单模态层** | `Mamba(bimamba_type="v2")` 或 `BiMamba3` | 正向扫描 + 反向扫描（`x.flip([1])`），输出相加 |
| **跨模态融合层** | 通过 Mamba-3 kernel `mamba3_siso_combined` / `mamba3_mimo_combined` | Mamba-3 本身不区分方向，双向性通过跨模态 B/C 注入实现 |

ISM 层的双向机制严格对齐 **Vision Mamba (Vim, ICML 2024)** 的 `bimamba_type="v2"`：独立两套 in_proj 参数分别处理正向/反向序列，共享 out_proj，输出 `y = y_f + y_b.flip(1)`。这使模型能同时捕获前向和后向的时序依赖。

当启用 `mixer_type="bimamba3"` 时，ISM 使用基于 Mamba-3 的 `BiMamba3`，支持 `fusion` 策略切换（`add` / `add_divide2` / `concat_proj` / `gated`）以及 MIMO 权重共享。

### 3.2 跨模态耦合策略（Coupled Cross-Modal Injection）

这是本模型 **最核心的技术创新**。其本质是将 Mamba SSM 重构为一种 **Cross-Modal State Space Attention**：

**理论对齐**：Mamba SSM 的核心递推公式为：

$$h_t = A_t h_{t-1} + B_t x_t, \quad y_t = C_t h_t$$

在标准 Mamba 中，$A_t, B_t, C_t, \Delta_t$ 全部来自同一个输入 $u_t$。本模型将其**语义拆解**为：

- **目标模态主导「如何读」**：$C_t$（读出矩阵 / Query）来自目标模态 → 决定从状态中读取什么信息
- **目标模态主导「如何衰减」**：$A_t, \Delta_t$（状态转移 / 离散化步长）来自目标模态 → 决定记忆的衰减动力学
- **源模态提供「写入什么」**：$B_t$（写入矩阵 / Key）和 $x_t$（输入值 / Value）来自两个源模态的加权融合 → 决定向状态中写入什么信息

这种设计精确对齐了 **Cross-Attention** 的 Q/K/V 语义，但完全在 SSM 的状态空间框架内实现，具备线性复杂度。

**三模态全耦合**：每层 `CoupledMamba3Fork` 同时执行三个方向的跨模态注入（T→A, A→T, V→T, T→V, ...），确保每个模态都能从另外两个模态获取互补信息。

**动态权重融合**：通过 `weight_net` 学习到的 softmax 权重，模型可以在不同时间步自适应调整两个源模态的贡献比例，例如在语音静默段更依赖视觉信息。

### 3.3 Mamba-3 状态空间模型

模型完整继承 Mamba-3 的核心技术特性：

| 特性 | 说明 |
|------|------|
| **Data-dependent A** | 状态矩阵 $A$ 通过 `-softplus(dd_A) + A_floor` 截断从输入数据动态生成，实现输入依赖的记忆衰减 |
| **Trapezoidal 离散化** | 使用 Trapezoidal 规则进行 ODE 离散化（而非 Euler），提供更高精度的连续系统近似 |
| **RoPE 旋转位置编码** | 在 SSM 的 B/C 通道上施加复数旋转位置编码，增强序列位置感知（`rope_fraction` 控制施加比例） |
| **RMSNormGated B/C** | 对 SSM 的 B 和 C 矩阵施加 RMSNorm + 门控归一化，提升训练稳定性 |
| **MIMO 支持** | Multi-Input Multi-Output 模式：通过 `mimo_rank` 控制 B/C 的低秩多通道扩展，增强 SSM 的表达能力 |
| **D-Skip 跳连** | 可学习的 D 参数提供直接的输入到输出跳连路径，缓解 SSM 的梯度消失问题 |
| **is_outproj_norm** | 在 out_proj 前施加 RMSNormGated 门控归一化 |

### 3.4 GLCE（Global-Local Context Extraction）

ISM 层中的 GLCE 模块结合了两种上下文提取：

- **Global Extractor**：`Linear(seq_len, seq_len)` 为每个位置聚合全局序列信息
- **Local Extractor**：`Conv1d(kernel_size=3)` 捕获局部相邻上下文
- **Shortcut**：输入直连，与全局+局部输出相加

这种设计使模型在进入 SSM 之前就能获得多尺度的上下文信息，弥补 SSM 对局部模式敏感度不足的问题。

### 3.5 双流残差与 Fused RMSNorm

ISM 的 `Block_GLCE` 采用**双流残差传递**：`(hidden_states, residual)` 两个张量并行跨层流动，结合 Triton 实现的 **fused_add_norm**（将残差加法与 RMSNorm 融合为单一 CUDA kernel），显著降低显存占用和计算延迟。

---

## 4. 总结

Coupled-BI-Mamba3 的核心架构创新可概括为：

> **以 Mamba-3 SSM 为基座，将 Cross-Attention 的 Q/K/V 语义迁移到状态空间框架中，实现高效的三模态耦合双向融合。**

通过最小侵入地 fork Mamba-3，模型在保留全部官方工程优化（Triton fused kernel、RMSNormGated、MIMO、RoPE 等）的同时，引入跨模态 B/C 注入和动态源权重网络，构建了一个端到端的多模态情感识别系统。
