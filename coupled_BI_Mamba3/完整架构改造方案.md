## Phase 2: 输入投影层升级

### 2.1 改造前架构

```python
# classifier.py 第 147-149 行
self.proj_text  = nn.Linear(text_dim, d_model)    # 768 → 128，单层线性
self.proj_audio = nn.Linear(audio_dim, d_model)   # 5 → 128，单层线性
self.proj_video = nn.Linear(video_dim, d_model)   # 20 → 128，单层线性
```

**问题**: 单层 Linear 从 768 维压缩到 128 维，信息损失严重。CAGMamba 和 MASCF 都使用至少 2 层 MLP + 非线性激活。

### 2.2 改造后架构

```python
# 新增 FeatureProjection 模块
class FeatureProjection(nn.Module):
    """两层 MLP 投影 + LayerNorm + GELU + Dropout
    参考: CAGMamba 的 proj_text/audio，MASCF 的 LSTM+Linear 投影"""
    def __init__(self, in_dim, out_dim, dropout=0.1):
        super().__init__()
        self.proj = nn.Sequential(
            nn.Linear(in_dim, out_dim),
            nn.LayerNorm(out_dim),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(out_dim, out_dim),
        )

    def forward(self, x):
        return self.proj(x)

# MSAClassifier.__init__ 中替换
self.proj_text  = FeatureProjection(text_dim, d_model, dropout=dropout)
self.proj_audio = FeatureProjection(audio_dim, d_model, dropout=dropout)
self.proj_video = FeatureProjection(video_dim, d_model, dropout=dropout)
```

### 2.3 理论依据

单层线性投影的学习能力为 $\mathbf{h} = \mathbf{W}\mathbf{x} + \mathbf{b}$，无法建模非线性关系。两层 MLP 引入非线性：

$$\mathbf{h} = \mathbf{W}_2 \cdot \text{GELU}(\text{LN}(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1)) + \mathbf{b}_2$$

GELU 激活函数：$\text{GELU}(x) = x \cdot \Phi(x)$，其中 $\Phi(x)$ 是标准正态分布的 CDF。相比 ReLU，GELU 在零点附近更平滑，更适合特征对齐任务。

### 2.4 预期提升

- 特征对齐质量提升，尤其是音频（5维 → 128维）和视频（20维 → 128维）
- 改动量：新增约 30 行代码

## Phase 3: 注意力池化替代均值池化

### 3.1 改造前架构

```python
# classifier.py 第 216-229 行
def _pool(self, x, mask=None):
    if self.pool_type == "mean":
        if mask is not None:
            x = x * mask.unsqueeze(-1).float()
            return x.sum(1) / mask.sum(-1, keepdim=True).clamp(min=1)
        return x.mean(dim=1)
    elif self.pool_type == "last":
        return x[:, -1, :]
    elif self.pool_type == "cls":
        return x[:, 0, :]
```

**问题**: 均值池化对每个时间步等权对待，忽略了不同时间步的信息量差异。对话中，关键情感词可能只出现在少数时间步。

### 3.2 改造后架构

```python
# 新增 AttentionPooling 模块
class AttentionPooling(nn.Module):
    """可学习的注意力池化
    参考: CAGMamba 的有效帧定位机制，AlignMamba-2 的 attention pooling"""
    def __init__(self, d_model):
        super().__init__()
        self.attn = nn.Sequential(
            nn.Linear(d_model, d_model // 2),
            nn.Tanh(),
            nn.Linear(d_model // 2, 1),
        )

    def forward(self, x, mask=None):
        # x: [B, L, D]
        scores = self.attn(x).squeeze(-1)  # [B, L]
        if mask is not None:
            scores = scores.masked_fill(~mask.bool(), float('-inf'))
        weights = F.softmax(scores, dim=-1)  # [B, L]
        return torch.bmm(weights.unsqueeze(1), x).squeeze(1)  # [B, D]

# 在 _pool 中添加
def _pool(self, x, mask=None):
    if self.pool_type == "attention":
        return self.attn_pool(x, mask)
    # ... 其余不变
```

### 3.3 理论依据

注意力池化的权重计算：

$$\alpha_i = \frac{\exp(\mathbf{v}^\top \tanh(\mathbf{W} \mathbf{h}_i))}{\sum_j \exp(\mathbf{v}^\top \tanh(\mathbf{W} \mathbf{h}_j))}$$

$$\mathbf{h}_{\text{pool}} = \sum_i \alpha_i \mathbf{h}_i$$

这等价于一个单头注意力机制，其中 query 是可学习向量 $\mathbf{v}$，key/value 是序列 $\{\mathbf{h}_i\}$。相比均值池化，它能自适应地聚焦于信息量大的时间步。

### 3.4 预期提升

- 对 MOSI/MOSEI 的回归任务：关键情感词的时间步会被赋予更高权重
- 对 IEMOCAP/MELD 的分类任务：情绪爆发帧会被聚焦
- 改动量：约 20 行新增代码

## Phase 4: 跨模态共享 A 矩阵 (SA-BSSM)

### 4.1 改造前架构

```python
# coupled_mamba3_fork.py CrossMamba3Cell
# 每个模态独立的 A 矩阵
self.in_proj_tgt = nn.Linear(d_model, d_model * expand * 2 + ...)  # 包含 dd_A
# A 由目标模态独立控制
A = -softplus(dd_A) + A_floor  # 每个目标模态有自己的 A
```

**当前数据流**:
```
Audio  → in_proj_A → [z_A, x_A, dt_A, A_A, ...]  ← 独立 A
Visual → in_proj_V → [z_V, x_V, dt_V, A_V, ...]  ← 独立 A
Lexical→ in_proj_L → [z_L, x_L, dt_L, A_L, ...]  ← 独立 A
```

### 4.2 改造后架构

```python
class CoupledMamba3Fork(nn.Module):
    def __init__(self, d_model, expand, d_state, ...):
        super().__init__()
        # 新增: 跨模态共享的状态转移矩阵
        d_inner = d_model * expand
        # 共享 A: S4D 初始化 [d_inner, d_state]
        A = repeat(torch.arange(1, d_state + 1, dtype=torch.float32),
                    'n -> d n', d=d_inner)
        self.shared_A_log = nn.Parameter(torch.log(A))
        self.shared_A_log._no_weight_decay = True

        # 每个 CrossMamba3Cell 仍保留独立的 B/C/D/dt/proj
        for tgt in ['audio', 'visual', 'lexical']:
            self.cells[tgt] = CrossMamba3Cell(
                d_model, expand, d_state,
                use_shared_A=True,  # 标志位
                shared_A_log=self.shared_A_log,
            )
```

```python
# CrossMamba3Cell 修改
class CrossMamba3Cell(nn.Module):
    def forward(self, u_tgt, u_s0, u_s1, shared_A_log=None):
        # ... in_proj_tgt 产生 z, x, dt, angles (不含 dd_A)
        if shared_A_log is not None:
            A = -torch.exp(shared_A_log.float())  # 共享 A
        else:
            A = -softplus(self.dd_A) + A_floor    # 独立 A (兼容模式)

        # B/C/D/dt 仍由各自模态独立控制
        B = w0 * self.b_proj(u_s0) + w1 * self.b_proj(u_s1)
        C = self.c_proj_tgt(u_tgt)
        dt = softplus(self.dt_proj_tgt(u_tgt) + self.dt_bias)
```

### 4.3 理论依据

SSM 状态更新公式：

$$\mathbf{h}_t = \bar{\mathbf{A}} \mathbf{h}_{t-1} + \bar{\mathbf{B}} \mathbf{x}_t$$

其中 $\bar{\mathbf{A}} = \exp(\Delta \cdot \mathbf{A})$ 是离散化的状态转移矩阵。

**共享 A 的含义**：所有模态的状态以相同的速率衰减/记忆。这强制不同模态在相同的时间尺度上演化，实现隐式的时序对齐。

**来源验证**：
- DepMamba (ICASSP 2025): MM-BiMamba 共享 `A_log`，音频和视频用同一个"时钟"
- TF-Mamba: TC-Mamba 中 (audio,text) 和 (video,text) 共享 A
- 两者都报告了显著的性能提升

### 4.4 预期提升

- 跨模态时序对齐增强，尤其是音频-视觉对齐
- 参数量减少：每个 CrossMamba3Cell 少一个 dd_A 投影层
- 改动量：约 40 行代码修改

### 5.2 改造后架构

```python
# 新增对齐损失模块
class AlignmentLoss(nn.Module):
    """OT + MMD 双对齐损失
    参考: AlignMamba-2 (Pattern Recognition 2026)

    核心思想: 在融合前，让不同模态的表示在统计和几何上对齐
    - OT 距离: 局部几何对齐 (token-level)
    - MMD: 全局统计对齐 (distribution-level)
    """
    def __init__(self, kernel_bandwidth='median'):
        super().__init__()
        self.kernel_bandwidth = kernel_bandwidth

    def forward(self, H_a, H_l, H_v=None):
        """
        H_a: [B, L, D] 音频 ISM 输出
        H_l: [B, L, D] 文本 ISM 输出
        H_v: [B, L, D] 视觉 ISM 输出 (可选)
        """
        loss = 0.0
        # 对 audio-language 和 (可选) video-language 对计算
        pairs = [(H_a, H_l)]
        if H_v is not None:
            pairs.append((H_v, H_l))

        for H_m, H_n in pairs:
            loss += self._ot_loss(H_m, H_n)
            loss += self._mmd_loss(H_m, H_n)
        return loss

    def _ot_loss(self, H_m, H_n):
        """Sinkhorn OT 距离 (entropy-regularized)"""
        # 余弦距离作为 cost matrix
        H_m_norm = F.normalize(H_m, dim=-1)  # [B, L, D]
        H_n_norm = F.normalize(H_n, dim=-1)
        C = 1 - torch.bmm(H_m_norm, H_n_norm.transpose(1, 2))  # [B, L, L]

        # Sinkhorn 迭代 (可微)
        log_p = torch.zeros_like(C)  # uniform initialization
        for _ in range(3):  # 少量迭代足够
            log_p = log_p - torch.logsumexp(log_p + C, dim=-1, keepdim=True)
            log_p = log_p - torch.logsumexp(log_p + C, dim=-2, keepdim=True)
        P = torch.exp(log_p)
        return (P * C).sum(-1).sum(-1).mean()

    def _mmd_loss(self, H_m, H_n):
        """Maximum Mean Discrepancy (Gaussian kernel)"""
        # flatten to [B, L*D]
        H_m = H_m.reshape(H_m.size(0), -1)
        H_n = H_n.reshape(H_n.size(0), -1)
        # Gaussian kernel
        def gaussian_kernel(x, y, sigma=1.0):
            xx = (x ** 2).sum(1).unsqueeze(1)
            yy = (y ** 2).sum(1).unsqueeze(1)
            xy = torch.mm(x, y.t())
            return torch.exp(-(xx + yy.t() - 2 * xy) / (2 * sigma ** 2))

        K_mm = gaussian_kernel(H_m, H_m)
        K_nn = gaussian_kernel(H_n, H_n)
        K_mn = gaussian_kernel(H_m, H_n)
        mmd = K_mm.mean() + K_nn.mean() - 2 * K_mn.mean()
        return mmd
```

### 5.3 理论依据

**OT 距离** (Optimal Transport):
$$W(\mu, \nu) = \min_{\mathbf{P} \in \mathcal{P}(\mu, \nu)} \sum_{i,j} P_{ij} C_{ij}$$

其中 $C_{ij} = 1 - \cos(\mathbf{h}_i^m, \mathbf{h}_j^n)$ 是余弦距离矩阵。加入熵正则化后可用 Sinkhorn 算法高效求解。

**MMD** (Maximum Mean Discrepancy):
$$\text{MMD}^2(\mu, \nu) = \mathbb{E}[k(\mathbf{x}, \mathbf{x}')] + \mathbb{E}[k(\mathbf{y}, \mathbf{y}')] - 2\mathbb{E}[k(\mathbf{x}, \mathbf{y})]$$

其中 $k(\mathbf{x}, \mathbf{y}) = \exp(-\|\mathbf{x} - \mathbf{y}\|^2 / 2\sigma^2)$ 是高斯核。

**互补性**：OT 捕获局部几何对齐（哪个 token 对应哪个 token），MMD 捕获全局统计一致性（两个分布的高阶矩是否匹配）。

### 6.2 改造后架构

```python
# 新增: 模态感知 MoE 投影
class ModalityAwareProjection(nn.Module):
    """MoE 投影: 模态专家 + 共享专家
    参考: AlignMamba-2 的 Modality-Aware Mamba Layer

    核心: 每个模态有自己的投影专家，同时有一个共享专家
    路由: 确定性路由 (按模态索引)，无需学习路由权重
    """
    def __init__(self, d_in, d_out, n_modality_experts=3, n_shared_experts=1):
        super().__init__()
        # 模态专家: T/A/V 各一个
        self.modality_experts = nn.ModuleList([
            nn.Linear(d_in, d_out) for _ in range(n_modality_experts)
        ])
        # 共享专家: 所有模态共享
        self.shared_experts = nn.ModuleList([
            nn.Linear(d_in, d_out) for _ in range(n_shared_experts)
        ])
        self.n_shared = n_shared_experts

    def forward(self, x, modality_idx):
        """
        x: [B, L, d_in]
        modality_idx: 0=text, 1=audio, 2=visual
        """
        # 模态专家输出
        mod_out = self.modality_experts[modality_idx](x)
        # 共享专家输出 (取平均)
        share_out = sum(e(x) for e in self.shared_experts) / self.n_shared
        # 残差融合
        return mod_out + share_out

# 在 CrossMamba3Cell 中使用
class CrossMamba3Cell(nn.Module):
    def __init__(self, d_model, expand, d_state, modality_idx):
        super().__init__()
        d_inner = d_model * expand
        total_proj = d_inner * 2 + dt_rank + d_state * 2 + ...

        # 替换单一 in_proj_tgt 为 MoE 投影
        self.moe_proj = ModalityAwareProjection(
            d_model, total_proj,
            n_modality_experts=3,  # T/A/V 各一个
            n_shared_experts=1,
        )
        self.modality_idx = modality_idx

    def forward(self, u_tgt, u_s0, u_s1, ...):
        # MoE 投影
        proj = self.moe_proj(u_tgt, self.modality_idx)
        z, x, dt, A, angles = proj.split(...)
        # ... 后续 SSM 计算不变
```

### 6.3 理论依据

AlignMamba-2 的 MoE 设计：
$$\text{MoE}_{\text{in}}(h_m) = E_m^{\text{mod}}(h_m) + E^{\text{shared}}(h_m)$$

其中 $E_m^{\text{mod}}$ 是模态 $m$ 的专属专家，$E^{\text{shared}}$ 是共享专家。

**为什么有效**：
- 模态专家学习每个模态的独特分布（音频的声学特征 vs 文本的语义特征）
- 共享专家学习跨模态共性（情感的普遍表达模式）
- 确定性路由（按模态索引）避免了 learned routing 的训练不稳定

- 每个模态的 SSM 参数更专精，减少模态间干扰

## Phase 7: 模态解耦与正交约束

### 7.1 改造前架构

```
当前 ISM 输出直接进入 CoupledMamba3Fork:
  ISM_text  → CoupledMamba3Fork → 融合表征
  ISM_audio → CoupledMamba3Fork → 融合表征
  ISM_video → CoupledMamba3Fork → 融合表征

问题: ISM 输出同时包含模态共享信息和模态专属信息，
      没有显式分离，导致跨模态融合时信息混杂
```

### 7.2 改造后架构

```python
class ModalityDecoupler(nn.Module):
    """模态解耦模块
    参考: DMD (CVPR 2023) 的特征解耦策略

    将每个模态的表示分解为:
    - shared: 模态共享的情感语义 (所有模态共享编码器)
    - private: 模态专属的物理特征 (每个模态独立编码器)

    约束: shared ⊥ private (正交损失)
    """
    def __init__(self, d_model):
        super().__init__()
        # 共享编码器 (所有模态共享权重)
        self.shared_encoder = nn.Sequential(
            nn.Linear(d_model, d_model),
            nn.ReLU(),
        )
        # 私有编码器 (每个模态独立)
        self.private_encoders = nn.ModuleDict({
            'lexical': nn.Sequential(nn.Linear(d_model, d_model), nn.ReLU()),
            'audio':   nn.Sequential(nn.Linear(d_model, d_model), nn.ReLU()),
            'visual':  nn.Sequential(nn.Linear(d_model, d_model), nn.ReLU()),
        })
        # 对齐投影 (用于计算正交损失)
        self.align_proj = nn.ModuleDict({
            'lexical': nn.Linear(d_model, d_model),
            'audio':   nn.Linear(d_model, d_model),
            'visual':  nn.Linear(d_model, d_model),
        })

    def forward(self, x, modality):
        shared = self.shared_encoder(x)
        private = self.private_encoders[modality](x)
        return shared, private

    def compute_orthogonality_loss(self, shared, private, modality):
        """正 CosineEmbeddingLoss with target=-1"""
        s = self.align_proj[modality](shared.flatten(1))
        p = private.flatten(1)
        return F.cosine_embedding_loss(
            s, p,
            torch.ones(s.size(0)).to(s.device) * -1
        )

# 在 MSAClassifier 中集成
class MSAClassifier:
    def __init__(self, ...):
        self.decoupler = ModalityDecoupler(d_model)

    def _encode(self, ...):
        # ISM 后解耦
        shared_l, private_l = self.decoupler(out_l, 'lexical')
        shared_a, private_a = self.decoupler(out_a, 'audio')
        shared_v, private_v = self.decoupler(out_v, 'visual')

        # 耦合融合使用 shared (跨模态对齐)
        feats = {'lexical': shared_l, 'audio': shared_a, 'visual': shared_v}
        for layer in self.layers:
            feats = layer(feats)

        # 最终表征 = shared + private (保留模态专属信息)
        out_l = feats['lexical'] + private_l
        out_a = feats['audio'] + private_a
        out_v = feats['visual'] + private_v
        return out_l, out_a, out_v
```

### 7.3 理论依据

DMD 的三重约束：

1. **正交损失**: $\mathcal{L}_{\text{ortho}} = \cos(\mathbf{s}_x, \mathbf{p}_x) \to -1$
   确保 shared 和 private 子空间正交，信息不泄漏

2. **重构损失**: $\mathcal{L}_{\text{recon}} = \|\text{Dec}([\mathbf{s}_x; \mathbf{p}_x]) - \mathbf{x}\|^2$
   确保分解不丢失信息

3. **循环一致性**: $\mathcal{L}_{\text{cycle}} = \|\mathbf{p}_x - \text{Enc}_p(\text{Dec}([\mathbf{s}_x; \mathbf{p}_x]))\|^2$
   确保编码器的稳定性

**总损失**:
$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{task}} + \lambda_{\text{ortho}} \mathcal{L}_{\text{ortho}} + \lambda_{\text{recon}} \mathcal{L}_{\text{recon}} + \lambda_{\text{cycle}} \mathcal{L}_{\text{cycle}}$$

### 7.4 预期提升

- 跨模态融合更干净：shared 空间只包含情感语义，private 空间保留模态特征
- DMD 在 MOSI/MOSEI 上验证了此策略的有效性
- 改动量：约 100 行新增代码

## Phase 8: 渐进式融合 (软融合 → 硬融合)

### 8.1 改造前架构

```
当前: 所有 CoupledMamba3Fork 层都做跨模态耦合扫描
  Layer 1: CoupledMamba3Fork (耦合扫描)
  Layer 2: CoupledMamba3Fork (耦合扫描)
  → 输出: 三个独立模态表征

问题: 没有"硬融合"阶段，最终表征仍是三个分离的向量
```

### 8.2 改造后架构

```python
class ProgressiveFusion(nn.Module):
    """渐进式融合: 软融合 → 硬融合
    参考: DepMamba (ICASSP 2025) 的 CoSSM + EnSSM 两阶段设计

    Stage 1 (CoSSM): 耦合扫描，模态流保持独立 (软融合)
    Stage 2 (EnSSM): 拼接 → 单流 BiMamba 深度融合 (硬融合)
    """
    def __init__(self, d_model, n_soft_layers, n_hard_layers, ...):
        super().__init__()
        # Stage 1: 软融合 (现有 CoupledMamba3Fork)
        self.soft_fusion = nn.ModuleList([
            CoupledMamba3Fork(d_model, ...) for _ in range(n_soft_layers)
        ])

        # Stage 2: 硬融合 (DepMamba 风格)
        fused_dim = d_model * 3  # 拼接 T+A+V
        self.hard_proj = nn.Linear(fused_dim, d_model)
        self.hard_mamba = BiMamba3(d_model, ...)  # 单流双向
        self.hard_norm = nn.LayerNorm(d_model)

    def forward(self, feats):
        # Stage 1: 软融合 (模态流独立)
        for layer in self.soft_fusion:
            feats = layer(feats)

        # Stage 2: 硬融合 (拼接 + 深度编码)
        fused = torch.cat([feats['lexical'], feats['audio'], feats['visual']], dim=-1)
        fused = self.hard_proj(fused)  # [B, L, d_model]
        fused = self.hard_mamba(fused)  # [B, L, d_model]
        fused = self.hard_norm(fused)

        # 均匀分配回各模态 (或只用 fused 做最终预测)
        return fused  # [B, L, d_model]
```

### 8.3 理论依据

DepMamba 的两阶段设计：
1. **CoSSM** (Cross-modal Selective State Space): 共享 A 矩阵的 MM-BiMamba，模态流保持独立但共享状态动态
2. **EnSSM** (Ensemble State Space): 拼接所有模态 → 单流 BiMamba，进行深度跨模态交互

**优势**：
- 软融合阶段保留模态特异性，避免过早信息混杂
- 硬融合阶段在统一表征空间中进行深度交互
- 渐进式设计符合"先对齐再融合"的认知科学原则

### 8.4 预期提升

- 最终表征包含更丰富的跨模态信息
- DepMamba 在抑郁检测任务上验证了此策略
- 改动量：约 60 行新增代码

```python
class TextAnchorCrossAttention(nn.Module):
    """文本锚点交叉注意力 + BiMamba
    参考: TF-Mamba 的 TQ-Mamba 设计

    流程:
    1. 文本作为 query，音频+视觉作为 key/value → 交叉注意力
    2. 交叉注意力输出 → BiMamba 时序建模
    3. 残差连接 + LayerNorm
    """
    def __init__(self, d_model, n_heads=8):
        super().__init__()
        self.cross_attn = nn.MultiheadAttention(
            d_model, n_heads, batch_first=True
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.mamba = BiMamba3(d_model, ...)
        self.norm2 = nn.LayerNorm(d_model)

    def forward(self, text_feat, audio_feat, visual_feat):
        # 拼接音频+视觉作为 KV
        kv = torch.cat([audio_feat, visual_feat], dim=1)  # [B, 2L, D]

        # 文本 query 交叉注意力
        attn_out, _ = self.cross_attn(text_feat, kv, kv)
        text_feat = self.norm1(text_feat + attn_out)

        # BiMamba 时序建模
        mamba_out = self.mamba(text_feat)
        text_feat = self.norm2(text_feat + mamba_out)

        return text_feat  # [B, L, D]

# 在 MSAClassifier 中集成
class MSAClassifier:
    def __init__(self, ...):
        self.text_anchor_attn = TextAnchorCrossAttention(d_model)

    def forward(self, ...):
        # ... 现有编码和融合 ...
        # 文本锚点精炼
        refined_text = self.text_anchor_attn(out_l, out_a, out_v)
        # 最终预测使用精炼后的文本 + 原始音频/视觉
        pooled = torch.cat([
            self._pool(refined_text, mask_t),
            self._pool(out_a, mask_a),
            self._pool(out_v, mask_v),
        ], dim=-1)
```

### 9.3 理论依据

TF-Mamba 的 TQ-Mamba 阶段：

$$\mathbf{H}_{\text{attn}} = \text{CrossAttn}(\mathbf{Q}_t, \mathbf{K}_{a \oplus v}, \mathbf{V}_{a \oplus v})$$

$$\mathbf{H}_{\text{out}} = \text{BiMamba}(\mathbf{H}_{\text{attn}})$$

**为什么文本作为锚点**：
- 文本通常包含最直接的情感词汇信息
- 音频和视觉提供补充的情感线索
- 交叉注意力让文本"查询"音视觉中最相关的信息

```python
# 5 组参数分组 (参考 CAGMamba)
def get_optimizer_groups(self, model):
    groups = []

    # 1. BERT/RoBERTa 参数 (低学习率)
    bert_params = [p for n, p in model.named_parameters()
                   if 'text_encoder' in n and 'bias' not in n and 'LayerNorm' not in n]
    groups.append({'params': bert_params, 'lr': 1e-5, 'weight_decay': 0.01})

    # 2. BERT bias/LayerNorm (无 weight decay)
    bert_no_decay = [p for n, p in model.named_parameters()
                     if 'text_encoder' in n and ('bias' in n or 'LayerNorm' in n)]
    groups.append({'params': bert_no_decay, 'lr': 1e-5, 'weight_decay': 0.0})

    # 3. Mamba 状态空间参数 (A_log, D): 低学习率
    mamba_state = [p for n, p in model.named_parameters()
                   if ('A_log' in n or '_D' in n or '_D_b' in n)]
    groups.append({'params': mamba_state, 'lr': 5e-4, 'weight_decay': 1e-6})

    # 4. Mamba dt 参数: 最保守
    mamba_dt = [p for n, p in model.named_parameters() if 'dt_proj' in n]
    groups.append({'params': mamba_dt, 'lr': 3e-4, 'weight_decay': 1e-5})

    # 5. 其他参数 (投影、融合、分类头): 高学习率
    other_ids = set()
    for g in groups:
        for p in g['params']:
            other_ids.add(id(p))
    other_params = [p for p in model.parameters() if id(p) not in other_ids]
    groups.append({'params': other_params, 'lr': 1.2e-3, 'weight_decay': 1e-4})

    return groups

# EMA (指数移动平均)
class EMA:
    def __init__(self, model, decay=0.999):
        self.model = model
        self.shadow = {name: param.clone().detach()
                       for name, param in model.named_parameters()}
        self.decay = decay

    def update(self):
        for name, param in self.model.named_parameters():
            self.shadow[name].data = (
                self.decay * self.shadow[name].data +
                (1 - self.decay) * param.data
            )

    def apply_shadow(self):
        self.backup = {name: param.clone()
                       for name, param in self.model.named_parameters()}
        for name, param in self.model.named_parameters():
            param.data = self.shadow[name].data

    def restore(self):
        for name, param in self.model.named_parameters():
            param.data = self.backup[name].data

# 修复: checkpoint 保存完整状态
def save(self, path, epoch, best_metric, optimizer, scheduler, ema):
    torch.save({
        'model_state_dict': self.model.state_dict(),
        'optimizer_state_dict': optimizer.state_dict(),
        'scheduler_state_dict': scheduler.state_dict(),
        'ema_state': ema.shadow if ema else None,
        'epoch': epoch,
        'best_metric': best_metric,
    }, path)
```

- A_log/D: 控制 SSM 动力学，对学习率极度敏感 → 0.5x lr
- dt_proj: 控制时间步长，最敏感 → 0.3x lr
- 投影层: 标准线性层，可承受更高学习率 → 1.2x lr
- 融合层: 需要快速学习跨模态模式 → 1.5x lr

**EMA**: 训练时用 shadow weights 推理，减少过拟合，CAGMamba 验证有效。

**AMP**: Mamba-3 的 Triton kernel 天然支持 FP16，AMP 可减少约 40% 显存。
